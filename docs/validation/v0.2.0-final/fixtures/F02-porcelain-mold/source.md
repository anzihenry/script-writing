# 《最后一炉》原稿
版本：draft-1。以下是三集连续正文。设定：本次浮雕订单必须使用师傅手雕的单件石膏母模 M01；工坊没有复制模，没有数字扫描，也没有替代母模。人物：陶艺师沈梨、徒弟阿禾。

## EP001
### S01 午后／内／灌浆间
[A01] 沈梨将 M01 放在台上，模沿缺口与内壁的鹤纹同时入镜。
[D01 沈梨／现场] 今晚交样，先把这一件灌出来。
[A02] 阿禾抱模时踩到水渍，M01 跌在地上碎成细块。沈梨逐块检查，鹤纹工作面全部断裂。
[D02 沈梨／现场] 整个面都毁了，今天补不回来。
### S02 午后／外／工坊废料池
[A03] 沈梨把 M01 的全部碎块倒进正在灌注的废石膏池，阿禾在旁看见。浆料覆盖碎块，师徒空手回屋。
[D03 阿禾／现场] 我去跟客户说延期。

## EP002
### S01 傍晚／内／灌浆间
[A01] 同一天，工坊无人进出，也未进行制模或修补。沈梨从台上拿起完整的 M01，模沿仍有同一个缺口，内壁鹤纹完整。
[D01 沈梨／现场] 就用师傅这只原模，花纹才能一样。
[A02] 阿禾扶住 M01，沈梨灌入泥浆，按约定时间倒浆，脱出完整的鹤纹坯。
### S02 夜／内／窑房
[A03] 两人把坯放上窑车推进电窑。沈梨合上窑门，将 M01 放回灌浆间的红色台架。

## EP003
### S01 次日清晨／内／窑房
[A01] 窑温降下，两人开窑。烧成的鹤纹样品完好。客户的视频通话亮起，沈梨将样品放到镜头前。
[D01 阿禾／现场] 没有迟到。
### S02 清晨／内／灌浆间
[A02] 沈梨把客户确认单贴在红色台架旁，M01 仍完整地放在台架上。

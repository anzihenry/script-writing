# 《潮汐呼号》原稿
版本：draft-1。以下为已完成三集全文；故事按顺序发生，无省略的联络或相遇。人物：电台员许岑、巡堤员林峤、船长老孟。

## EP001
### S01 夜／内／海堤电台
[A01] 许岑拔掉烧坏的联网模块，手机屏幕显示无服务。窗外林峤敲窗，她隔玻璃指向堤外，让他去找失联的老孟。林峤点头离开；隔音玻璃两侧均听不见对方。
[D01 许岑／现场] 再等五分钟，我就开应急灯。
### S02 夜／内／海堤电台
[A02] 林峤离开后，老孟从短波机中呼叫。镜头始终留在室内。
[D02 老孟／无线电] 公共航道被堵了。我走七号涵洞，靠南壁停船。只告诉你，别让围观的人堵出口。
[D03 许岑／现场] 收到，七号涵洞，南壁。
[A03] 许岑写下位置，刚按发射键，电台断电。窗外已不见林峤。她打开手电，沿唯一的堤路出发。

## EP002
### S01 夜／外／堤路
[A01] 连续接上集：许岑迎面遇见仍独自行走的林峤。两人此前没有再次接触，林峤没有携带任何收发设备。
[D01 林峤／现场] 七号涵洞南壁太低。老孟既然停在那里，就从南壁凿口。
[A02] 许岑立即把手电交给林峤，两人转身奔向涵洞；她未出示纸条，也未说过船的位置。
### S02 夜／外／七号涵洞
[A03] 林峤按自己刚才说的位置凿开薄木挡板，灯光照出老孟的船头。
[D02 老孟／现场] 幸亏你们直接找到南壁，再找错一次就来不及了。

## EP003
### S01 黎明／外／涵洞出口
[A01] 两人扶老孟上堤。许岑用绳子把船系在石桩上，林峤把手电递回许岑。
[D01 林峤／现场] 我去叫人来拖船，你陪他。
[A02] 林峤跑向恢复供电的岗亭。老孟坐下，许岑替他裹紧雨衣。

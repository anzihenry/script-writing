# 《幕布之后》原稿
版本：draft-1。全剧三集，三集均已完成，下文没有缺页。
创作计划（不是正文事实）：伏笔 F-RED 为旧幕布下摆的红线；EP001 投放，EP003 必须由白露拆线取出父亲写给她的信，解释父亲为何卖掉剧团，并完成父女误会的和解。未批准延期或取消。
人物：修复师白露、剧场经理周叔。父亲已去世，不出场。

## EP001
### S01 下午／内／旧剧场
[A01] 白露拆下最后一排椅罩。周叔指向舞台上待拆的旧幕布。
[D01 周叔／现场] 拆之前看看下摆。你爸临走那天，亲手缝了一道红线，说你回来就会明白。
[A02] 白露蹲下，指尖划过一段突起的红线，线内有扁平的硬物轮廓。她刚拿起剪刀，楼上传来漏水声。
[D02 白露／现场] 先救设备，幕布留着，明晚封场前我来拆。

## EP002
### S01 次日上午／内／配电间
[A01] 白露与周叔把设备搬到干燥地面，水管终于关紧。她将剪刀收进工具袋。
[D01 周叔／现场] 明晚之后这里改仓库。你不想知道他留下什么？
[D02 白露／现场] 他卖剧团连句解释都没有。我想知道，但我怕又是叫我别唱戏。
### S02 上午／内／舞台
[A02] 白露挂起“幕布保留，勿拆”纸牌。她隔着布摸了摸那块硬物，转身去清点灯具。

## EP003
### S01 次日晚／内／剧场门厅
[A01] 白露交清灯具，周叔把收据递给她。舞台在门厅后方，旧幕布仍悬挂着，红线完整，纸牌未摘。
[D01 白露／现场] 设备一件没少，工作结束了。
[D02 周叔／现场] 明天施工队就来了。
[A02] 白露把工具袋拉链合上，与周叔一同走出剧场。
### S02 夜／外／剧场门口
[A03] 周叔拉下卷帘。白露朝他点头，独自离开；没有取走幕布或其中的硬物。画面渐黑，字幕“全剧终”。

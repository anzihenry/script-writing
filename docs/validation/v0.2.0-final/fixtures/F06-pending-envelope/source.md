# 《晴天候车》原稿
版本：draft-1。全季计划六集，目前只完成 EP001–EP003，以下即本次审查全部正文，不代表全季终稿。
计划条目：F-BLUE 蓝信封将在 EP005 由宁可当面拆开；拟写内容是父亲留下的公交车改线申请，但 EP004–EP006 尚未写，计划未变更。
人物：宁可、退休司机父亲宁海、调度员方晴。

## EP001
### S01 早晨／内／宁家餐厅
[A01] 宁海把未封口的蓝信封 E01 放到餐桌上。宁可没拿起来。
[D01 宁海／现场] 等你轮休的时候，我们再一起看。
[D02 宁可／现场] 周五吧。今天我得先把末班车的事问清楚。
[A02] 宁海把信封收进自己的帆布包，带包出门。镜头没有展示信封内部。

## EP002
### S01 次日上午／内／公交调度室
[A01] 宁可在方晴面前展开一张新的乘客联名表，与 E01 无关。
[D01 宁可／现场] 最后一个班次提前了，桥西的夜班工人赶不上。
[D02 方晴／现场] 我只能受理申请，不能今天就答应恢复。
[A02] 方晴在联名表上盖收件章，复印一份交给宁可。原件留在方晴桌上。

## EP003
### S01 当晚／内／宁家餐厅
[A01] 宁可把带收件章的复印件交给父亲。宁海读完，放到餐桌上。
[D01 宁海／现场] 你先把人家的困难讲明白，比吵架管用。
[D02 宁可／现场] 还没结果。我明天去统计下车人数。
[A02] 宁海打开帆布包，确认 E01 还在原处，随即拉好拉链。宁可在另一头洗杯子，没有看到袋中物品。
[D03 宁海／现场] 周五的约定还算数？
[D04 宁可／现场] 算数。
[A03] 宁可擦干杯子，打开空白统计本。父亲把帆布包挂到自己椅背上。本集结束。

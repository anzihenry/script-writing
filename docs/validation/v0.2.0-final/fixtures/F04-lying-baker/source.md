# 《糖霜指纹》原稿
版本：draft-1。全剧两集。人物：面包师桑宁、店员阿策。正文按时间顺序发生。

## EP001
### S01 清晨／内／烘焙店后厨
[A01] 桑宁独自在后厨，拿起纸袋 P01，从抽屉取出装着周年纪念戒指的盒子放进去，再铺上饼干。她将纸袋封口藏到冷柜顶上。玻璃反光确认阿策还未到店。
[D01 桑宁／内心] 下班再给他，不能让他提前猜到。
### S02 清晨／内／店面
[A02] 阿策进店，看见桑宁袖口沾着金色糖霜，又望向冷柜顶的纸袋。
[D02 阿策／现场] 那里面是什么？
[D03 桑宁／现场] 只是昨天剩的饼干。那种戒指我可没买，太贵。
[A03] 阿策挑眉。桑宁转身揉面，镜头给到她背着阿策偷偷笑的嘴角。
[D04 阿策／现场] 我又没问戒指。

## EP002
### S01 夜／内／烘焙店后厨
[A01] 桑宁从冷柜顶取下仍封着的 P01。阿策在她面前拆开纸袋，从饼干下取出戒指盒并打开。
[D01 阿策／现场] 原来你早上骗我。
[D02 桑宁／现场] 是，骗了一整天。周年快乐。
[A02] 阿策把戒指戴到手上，把空盒放回纸袋。桑宁接过纸袋放到柜台下。
[D03 阿策／现场] 我猜到了是礼物，可真没猜到你会买这个。
[A03] 两人一起关灯。阿策手上的戒指反着门口的灯光。

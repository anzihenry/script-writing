## 新旧版本的实质差异与因果核对

v1.0 bible 明写林夏见过完整页；EP002 D002“七号库的？”与 B002“故意说错”依赖该先验。v2.0 bible 明确从未见过完整页；EP002 D002 改成“就一张纸，你急什么？”，D003 是来访者自行说“登记簿里剩下的，也给我”，D004 才追问“我没提登记簿。你怎么知道？”。此前 EP001 全部对白没有透露登记簿，门不透明且关闭；因此此处可听见的关联不需要林夏预知三号、第四行。

来访者的“说漏”略直白，但有 EP001 先催开门、随后索纸的焦急铺垫；它提供关联证据而未独自解决身份/盗窃责任，因此不是无铺垫解围。EP002 的“我说错了”也未被台账当成有效解释。EP003 保存页角、按呼叫键并不追出，兑现守住证据；未接通的铃声没有被当作管理处已答应到场。“我等他们来”可作为人物意愿而非客观保证。

EP001/EP003 新正文除版本标题外延续原场内内容，属合理的依赖复核更新：两集原来没有编号先验台词。EP002 D002–D005 和 B002/B003/B005/B006/B007 有实质变更，相应台账与交接同步。六份导出对白逐条一致，42个动作块均对应正文；本审查另按对白意义与道具状态复核，没有以机器字段匹配替代因果判断。

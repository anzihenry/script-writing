# 设定与制作约束 v1.0

CHAR001 林夏：新任管理员，谨慎、措辞短，起初怕误会来访者，逐步选择主动试探并保留证据。她当班前见过完整登记页，记得“三号、第四行”；当班后发现该页被撕。此记忆是既有知识，不能改写为对来访者身份的了解。
CHAR002 来访者：陌生人，仅画外声，礼貌掩饰焦急；知道缺页记录，希望取回页角，但不说明自己如何得到钥匙或是否参与偷窃。

LOC001 值班室：不透明门、投递缝、桌面、固定墙面管理处呼叫器。呼叫键启动铃声不等于有人已接通，也不增加第三名说话角色。
PROP001 无刻字铜钥匙。PROP002 登记簿及其撕下页角，按同一道具的部件管理，独特撕口可对合。灰外套固定，无伤势变化。只有林夏在室内，对方无法看到桌面，不知道她已比对纸片。

因果：收到钥匙与纸片→纸片匹配缺页→故意报错编号→对方纠正并说出行号→确认其了解登记信息→对方直接索纸→林夏保留证据并呼叫管理处→对方离去。知道记录不等于证明偷窃，结局不冒认抓到窃贼。

生产：两张静帧与反应镜头表达撕口匹配；手部操作可切镜；不要求生成可读编号、复杂接触或长镜头。关键证据是图形吻合与对话，不靠生成中文文字。

## 已知边界

- 格式检查不能验证“实际已读”或接受依据的真实性；报告如实保留作者自审身份。
- script-json 为新格式的权威对白；自由散文不自动解析。MATCH 不含动作语义、表演和任意散文与结构化块的同步。
- 索引按已提取状态工作。没有记录的字段是未知；来源失效或覆盖缺失不能称当前状态有效。
- 影响分析按文件依赖保守传播，复核决定不自动让过期产物恢复有效。
- 多文件追加在捕获到写入异常时回滚；不承诺进程被强杀或断电时具备文件系统事务语义。
- 不支持并发写入、插集重排、任意 Markdown 解析和通用生产图。

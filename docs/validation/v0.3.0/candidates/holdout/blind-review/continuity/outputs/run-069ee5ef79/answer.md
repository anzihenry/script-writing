# 《铜锁》三场道具连续性核对

输入：`input/source.md`，《铜锁》v1.0。输出：`output/answer.md`，审核报告 v1.0；本次专项审核已完成，原稿未改。范围仅限 EP001-SC001、EP002-SC001、EP003-SC001 的铜锁状态，不涉及其他情节或全季结论。为便于定位，本文将唯一铜锁暂标为 PROP001，仅作本报告引用，不代表已建立项目台账。

结论：一处确定的道具硬冲突，发生在第三场；第二场是角色话语与既定事实不符，尚不能单独判作道具穿帮。最小修复应保留第一场的不可逆销毁，局部更换第三场的锁门动作；是否澄清第二场台词，取决于甲此处是否有意说假话。

## Q001：原铜锁销毁后重新出现并使用——确定冲突

对象：PROP001。前后场：EP001-SC001 → EP003-SC001，经过 EP002-SC001。

证据链不依赖猜测：第一场既说明“唯一”，又说明“熔成铜水，无法复原”；第三场指明是“EP001那把原铜锁”，且以客观动作完成锁门。输入还排除了复制品、闪回及复原机制，因此不能用另一把同款锁、过去时画面或隐藏修复来解释。

首个客观状态分歧是第三场“甲拿出……原铜锁”这一动作。后续“当场锁住门”继续依赖这把不存在的完整锁，属于同一问题的影响范围。第二场的声明是更早出现的事实不符话语，但不是原锁客观重现的证据，不应把硬冲突的起点误报到第二场。

最小修改建议：只替换第三场这一条动作，保留甲封住门的叙事作用。例如将其改为：“甲合上门，插上门内的门闩。”这是局部创作提案，门闩并非输入中已有事实；采用时需确认门的布景允许该动作，并在动作发生处让门闩可见。这样不必改动第一场，也不引入新铜锁或复原设定。若后续必须依靠‘铜锁’本身而非关门结果，当前三场不足以确定替代方式，需另核对其用途；本次不自行添加后续剧情。

## Q002：甲的持有声明——待核实，不作硬冲突定论

对象：PROP001；位置：EP002-SC001。台词“我留着那把锁”按字面与第一场销毁事实不符，但角色可以撒谎或判断错误，角色发言不等于叙事层面的事实。镜头给空手也只能说明此刻手中无锁，不能单凭空手证明没有藏在其他位置；真正限制原锁存在的是第一场的明确销毁。

最小处理分两种意图：若甲在撒谎或逞强，这句可保留，不必为了道具连续性强行修改，也不宜擅自添加作者未给出的动机。若这句本意是向观众真实交代道具状态，可仅改为“那把锁已经熔了。”此修改是建议，不表示原稿已经采用。是否保留假话是唯一需作者确定的意图项，但不影响第三场硬冲突的成立。

本次未发现可据以确认其他道具问题的材料。建议采用第三场局部替换后，只复核新的封门动作是否成立，并检查第二场台词是否符合甲的意图；未执行改稿、台账更新或整场重写，也不将待核实的动机认定为事实。

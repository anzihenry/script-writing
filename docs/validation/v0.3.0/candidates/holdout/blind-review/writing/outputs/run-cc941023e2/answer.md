# 《渡船票房》EP001《留一张》

G3 单集正文｜v1.0｜draft（已作本集自检，未独立审稿）

来源：input/request.md、input/brief.md；原创试写，无前集依赖。暂定售票员为主角，不另起姓名。暂定这是当天末班船，售票员也要乘它回家；两张票均为本班不记名普通客票。以下约 80 秒，含末尾停留，不另加片头尾。

人物：CHAR001 售票员；CHAR002 旅客。
常驻场景：LOC001 渡船票房售票窗口，黄昏。两场为同地连续时间，窗框、台面和拉窗属固定布景。无第三人、画外人声或外景插入。
主要道具仅三件：PROP001 旅客的票；PROP002 自带印油的“作废”章；PROP003 售票员自己的有效船票。两张票背面颜色不同，以便辨认。

## EP001-SC001｜内／外窗口两侧｜黄昏｜0—32 秒

入场：旅客的票刚被收进窗口；售票员急着收工。旅客要取回票，售票员想结束争执赶船。

**EP001-SC001-B001｜0—7 秒**

售票员低头，“咔”一声把章压在旅客的票上，推到台面内侧。她抽出自己胸袋里的另一张票，夹在指间，另一只手开始拉窗。

旅客俯身看见红章，手掌贴住窗框。

**EP001-D001｜CHAR002 旅客｜现场**：等等！我让你看哪班，没让你作废！

**EP001-SC001-B002｜7—20 秒**

售票员停手，把两张票并排。两张票上印的都是“末班”。她看一眼章，再看旅客。拉窗停在半开处。

**EP001-D002｜CHAR001 售票员｜现场**：……我当你退票。盖错了。

**EP001-D003｜CHAR002 旅客｜现场**：那把票还我。

**EP001-D004｜CHAR001 售票员｜现场**：有这个章，过不了。

旅客伸出的手没有收回。

**EP001-SC001-B003｜20—32 秒**

售票员把自己的票收回胸前，朝窗口外侧偏一下身，仍想离开。

**EP001-D005｜CHAR001 售票员｜现场**：明早我给你补。这是末班，我也得坐它回家。

**EP001-D006｜CHAR002 旅客｜现场**：你今天回，我就该明天回？

售票员握住拉窗的手松开。窗不动了。

出场变化：错误已由售票员亲口承认；两人都知道，只等明早会把错误的代价留给旅客。

## EP001-SC002｜同一窗口｜紧接｜32—80 秒

入场：窗口半开，两张票仍在售票员一侧。她必须决定谁承担误盖章的损失。

**EP001-SC002-B001｜32—46 秒**

售票员将自己的票放到旅客伸着的手前，手指压着票角。旅客看看她，没抽。

**EP001-D007｜CHAR002 旅客｜现场**：你的？

**EP001-D008｜CHAR001 售票员｜现场**：嗯。这班，不记名。拿着。

**EP001-D009｜CHAR002 旅客｜现场**：那你呢？

售票员看向窗口外，拇指摩挲票角，两秒后把手彻底撤回。

**EP001-SC002-B002｜46—61 秒**

**EP001-D010｜CHAR001 售票员｜现场**：今晚回不去了。

旅客拿起有效票，又指向被作废的那张。

**EP001-D011｜CHAR002 旅客｜现场**：那张，也还我。

售票员把废票推来。旅客用有效票盖住废票上的红章，对齐，又将两张错开。

**EP001-D012｜CHAR002 旅客｜现场**：我拿了你的，你别又说成我退的。

**EP001-SC002-B003｜61—73 秒**

售票员看着红章，把废票翻回正面，推向旅客。

**EP001-D013｜CHAR001 售票员｜现场**：拿着。是我盖错的。

旅客收起两张票，向窗口外退开半步。他不再拦窗。

**EP001-D014｜CHAR002 旅客｜现场**：明早，我把这张错票送回来。

**EP001-D015｜CHAR001 售票员｜现场**：不用。你留着。

**EP001-SC002-B004｜73—80 秒**

旅客转身，离开画面。镜头留在窗口内。

售票员下意识摸了一下空胸袋。她把章往台面深处推，拉拢窗口。窗合上后，透过玻璃仍能看见她站在原处；她没有像开场那样急着走。

切黑。

出场变化：旅客取得有效票，并保留误盖的凭据；售票员交出了自己的返家机会，承担当晚不能乘船回家的实际代价。关窗动作完成，承担错误的选择也已无法靠一句道歉收回。

## 本集收束

胶带已由完整缠绕变为林禾手中的断片；损失发生在镜头内，无法靠一句承诺撤销。她支付的代价是亲手破坏父亲留下的原样，换来的只是检查机会，并非保证修好。老周接到可拆的灯，双方从互相阻挡转为共同面对灯内故障。灯仍未通电、未修复；结尾不以突然亮灯解围。

时长按约3–4字／秒及动作停顿估算，总计80秒；对白与同块动作重叠部分不重复计时。合理表演浮动约75–88秒，尚未实际朗读。手部撕带为关键可见动作，制作时保留撕前完整缠绕、撕裂瞬间及断片三个连续状态；若拆盖动作耗时，采用接缝已松开的近景承接，不省略林禾主动撕断的选择。

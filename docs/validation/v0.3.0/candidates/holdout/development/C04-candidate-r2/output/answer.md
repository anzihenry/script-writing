# 三场道具连续性核对

本次只核对铜锁的实物状态。结论：**确定冲突一处，首次出现在 EP003-SC001 的客观动作；EP002-SC001 只有角色说法与既定事实相悖，不能据此认定铜锁已经重新出现。** 最小修改应落在第三场的锁门工具上，无需重写整场。

输入：`input/source.md`《铜锁 v1.0》及 `input/request.md`。输出：`output/answer.md`，审核报告 v1.0；状态为本次三场道具专项核对完成、修订建议未实施。阶段：连续性审核。本文将唯一原铜锁暂记为 PROP001，仅作报告内定位，不冒充已有项目资产编号。

## 逐场状态与证据

| 场次 | 原文证据 | 能确认的道具状态 |
| --- | --- | --- |
| EP001-SC001 | “唯一铜锁被熔成铜水，无法复原” | 旁白明确确认原锁已毁，完整锁体及锁门功能不再存在。铜水的后续位置、持有人未交代，不能自行补定。 |
| EP002-SC001 | 甲说“我留着那把锁”；镜头给出“他空着的手” | 只能确认甲作出留锁的声称、此刻手中没有展示锁。没有客观画面证明他持有原锁，更没有原锁恢复的事件。 |
| EP003-SC001 | “甲拿出EP001那把原铜锁，当场锁住门” | 客观动作断言原锁完整存在、由甲持有且能使用，与第一场确认的不可逆毁损直接冲突。 |

状态追踪应沿用第一场的已毁事实，直到出现合法的状态变化证据；第二场对白本身不能把“已熔毁”更新成“甲持有完整原锁”。材料还明确排除了复制品、闪回、复原机制，因此第三场没有可用的既有解释。

## Q001：原铜锁不可逆毁损后重新使用

对象：PROP001。前后场：EP001-SC001 → EP003-SC001。首个客观分歧：第三场“拿出EP001那把原铜锁”，随后的“锁住门”继续扩大同一冲突，使原锁不仅重新存在，还恢复了功能。这两处属于一个道具状态错误，不应重复报成两个独立问题。

影响范围：当前已知为第三场取锁、锁门的动作及其成立依据。第一场建立的不可复原事实无需因后场动作而被否定。第二场的台词需要结合作者意图核实，但不足以把首次实物冲突提前。未提供其他场次，不推定全季影响。

**建议采用的最小补丁：** 将第三场这一个动作句替换为：“甲取出一把普通铁锁，当场锁住门。”这里的铁锁是修订提案中新设的独立道具，不是原铜锁、复制品或恢复后的物件。这样保留甲锁门的行为与即时结果，只取消该行为对已毁原锁的依赖；第一场保持不动。补丁成立的前提是本场只需要“锁住门”，不需要靠原铜锁的身份证明别的情节。材料没有给出后一要求，因此暂以保留锁门结果作为最小修订目标。

若原铜锁的身份本身必须参与后续情节，则这个补丁不足，需要另行调整第一场的毁损设定；这将触及既定事实，不是本次优先建议，也不应擅自用“藏了第二把”“其实没熔”来解释。

## Q002：第二场台词的事实口径待核实

甲说“我留着那把锁”，与旁白确认的事实不一致，但角色可能说谎、误认或使用非字面表达；现有材料不能确定是哪一种，也不能确认作者失误。“空着的手”仅证明当下没有手持展示，不能单独证明口袋或别处没有物件；判断原锁已毁的依据仍是第一场旁白。

最小处理：若此句意在表现隐瞒或不可靠陈述，可保留，不必为了道具连续性强改。若作者意在让甲如实交代原锁去向，可只改此句为：“那把锁已经熔了。”无需增加解释性整场对白。此项为条件建议，不把尚未确认的说谎动机写成事实。

未决项仅为第二场台词是否有意不实，以及第三场是否必须保留原锁身份。没有实际台账可供比对，本报告依据三场原始文字作结论；未改正文、未更新台账，也未宣称修订后已通过复核。采用补丁后，只需复核这三场的毁损事实、甲的声称与第三场新锁身份是否一致。

# 《灯具店》EP001《不亮也留》

单集分场正文 v1.0｜工作稿，已作本集文本自检。
来源：input/request.md、input/brief.md。暂定姓名：物主陈禾（CHAR001，主角）、修理工老周（CHAR002）。父亲不出场；不设画外音、闪回或第三人。

唯一场景 LOC001：灯具店维修台，内景，傍晚。主要道具三件：旧台灯（PROP001，电线、插头及底座脚为固有部件）、父亲缠的旧胶带（PROP002）、斜口钳（PROP003）。台面为固定布景。台灯全程未接电。

本集变化：陈禾要把唯一的台灯修亮，又不许拆父亲留下的胶带；最终亲手放弃它的照明用途，留下能站稳的旧灯。

内景／傍晚／LOC001，时间连续。人物：CHAR001、CHAR002。

入场：陈禾将歪着灯头的旧台灯推过维修台。她要当晚取走；老周要拆开检查，胶带封着需要打开的接缝。

## EP001-SC002｜留下什么

内景／傍晚／LOC001。紧接上场，无换景、无时间跳跃。人物、道具同上。

入场：台灯退到陈禾面前；她必须在继续使用与保住原样之间选择。

## Q001：原锁毁灭后作为完整锁具再次使用

对象：PROP001。对照场次：EP001-SC001 → EP003-SC001。

冲突不是缺一段“甲取回锁”的过场：取回不能把铜水变回锁。正文还明确排除了复制品、闪回和复原机制，因此无法借同款替身、时间倒叙或隐含修复来解释。首个**客观状态分歧**出现在第三场“拿出……原铜锁”；紧随其后的“锁住门”进一步确认其功能完好。第二场是更早的口头不一致，但尚未改变原锁的事实状态。

影响范围：第三场原锁出场及用它锁门的动作必须处理；第二场台词的含义需保持清晰。现有材料没有其他场次、实际台账或衍生文件，无法认定后续影响，更不声称已同步任何记录。

**推荐最小修改：只替换第三场的一句动作。**

> 原句：甲拿出 EP001 那把原铜锁，当场锁住门。  
> 建议句：甲拿出一把另买的铁锁，当场锁住门。

这是一项修改提案，新增“另买铁锁”的信息，不是对原文已有事实的认定。它保留“甲锁住门”的动作结果，明确用另一件锁具完成，不让原铜锁复原，也不使用原锁复制品。后续若采用此改法，两件道具必须分别标识，铁锁不得继续标为 PROP001。仅删掉“EP001 那把原”而仍写“铜锁”不够稳妥，观众可能继续将其认作前述唯一铜锁。

若不允许新增任何锁具，可将第三场改为“甲摸向空处，随即转身抵住门”。这能消除原锁复现，但会将“锁牢门”改为“用身体阻门”，动作效果不同，因此作为备选，不与推荐方案同时采用。无需为保留原锁而推翻第一场的毁锁事实。

## Q002：第二场持有声明的意图待核实

“我留着那把锁”可能是谎言、逞强或自我欺骗，现有材料不能确定是哪一种。空手镜头可以形成疑点，却不直接证明台词的心理含义。故本项标为**待核实的角色陈述**，不判定道具持有硬错误，也不擅自补写甲的动机。

最小处理是保留第二场，先修复第三场硬冲突。若作者明确要求甲在此诚实表达字面事实，再调整这句台词，例如“那把锁已经没了”；此改法会改变人物表达，不能作为必改项自动执行。

# 《旧照相馆》EP001《先松手》

G3 单集正文｜v1.0｜draft  
输入：本 run 的 input/request.md、input/brief.md。原创试写，姓名及交易细节为暂定设定。

人物：CHAR001 店主老周（主角）；CHAR002 顾客林岚。  
常驻场景：LOC001 旧照相馆柜台，内景，傍晚；两场连续，无转场、无其他人声。  
主要道具共三件：PROP001 已显影底片一条；PROP002 修复样照一张；PROP003 三百元修复账单一张。柜台为固定布景，无新增手持物。  
目标时长：60–90 秒；本稿估算 82 秒，不另加片头片尾。

## EP001-SC001｜柜台前｜0–37 秒

林岚刚接过底片验看，捏着片边。样照与账单留在柜台上。老周要拿回底片继续修复，却坚持先收款；林岚要看到修复效果才付款。

**EP001-SC001-B001｜0–9 秒**

老周伸手。林岚把底片收至胸前，手掌避开影像区。

**EP001-D001｜老周 CHAR001｜现场：** 底片给我。三百结了，我再修一遍。

**EP001-D002｜林岚 CHAR002｜现场：** 先付？再把我修成这样？

她将样照转向老周。

**EP001-SC001-B002｜9–23 秒**

样照上，脸部被过度磨平，嘴角像一块浅白的蜡。林岚指腹停在嘴角旁，随后指向自己嘴角一小道疤。

**EP001-D003｜林岚｜现场：** 这道疤是我的。你给抹没了。

**EP001-D004｜老周｜现场：** 我能补回来。可前面那几个钟头，也得算钱。

他说着，把账单往她面前推。她不接。

**EP001-SC001-B003｜23–37 秒**

**EP001-D005｜林岚｜现场：** 所以修错了，也得我先买单？

老周的手仍悬着。林岚绕开那只手，往画面内的门口方向退一步。

**EP001-D006｜老周｜现场：** 你拿走，我就没法改了。

**EP001-D007｜林岚｜现场：** 我留下，你就能让我先付了。

老周张嘴，又闭上。伸出的手慢慢落到柜台边。

场末：钱未付，底片仍归林岚持有；她准备离开，老周失去继续修复的机会。

## EP001-SC002｜同一柜台，紧接上场｜37–82 秒

**EP001-SC002-B001｜37–53 秒**

老周拿起账单。拇指搓过纸边，停住。他看一眼样照，再看林岚嘴角。

他将账单从中撕开，把两半摊在柜台上。

**EP001-D008｜老周｜现场：** 三百作废。是我修错了。

撕纸声落下后，留两秒静默。

**EP001-SC002-B002｜53–66 秒**

林岚站住，底片仍贴着胸前。

**EP001-D009｜林岚｜现场：** 我不给你底片，也不收钱？

老周将样照推到她能够拿到的柜台外沿，自己侧身，让开她通向门口的路。

**EP001-D010｜老周｜现场：** 不收。你拿走。

林岚看一眼他让出的路，再看柜台上的两半账单。老周不再伸手。

**EP001-SC002-B003｜66–82 秒**

林岚走回柜台，将底片轻放在干净台面上，推向老周。她用食指按住样照被抹平的嘴角。

**EP001-D011｜林岚｜现场：** 那就再修一次。疤，留着。

老周捏住底片两端边缘，拿起；空出的手将撕开的账单推离工作区域。

**EP001-D012｜老周｜现场：** 留着。

林岚没有走。她将样照转正，放在两人之间。老周俯身比对底片与样照；她站在柜台另一侧，看着他的手。

切黑。

## 假设与实验

M2 的 S01 输出曾出现日景被称为“昨晚”、次日场头与“明早”混用、持物衔接缺少重新拿起等额外发现。假设：在单集技能入口补充条件式的时间锚点与持物转移检查，能减少这类错误。候选只修改 `ai-short-drama-episode/SKILL.md` 一处；其余规则及共同任务保持相同。冻结规则保存在 frozen/baseline 和 frozen/candidate，生产技能没有采用该候选。

使用原开发任务 S01（目标）与 W01（写作回归），每条件每任务两次，共八次独立上下文、串行运行。原 M2 必达项保留，S01 在运行前增加相对时间和持物衔接两项事实一致性检查；本轮评分不能直接与 M2 相减。模型标识、token 和费用未知，宿主技能目录可见，隔离为指令约束。匿名评分也可能通过输出路径或方法被猜出条件，属于部分盲化。

读取量来自执行者自报路径，按文件字节计，可能包含部分读取却按全文件计量及工具内部读取口径差异；不等同模型实际输入 token，也不能推算费用。耗时是开始至采集的上界；W01-candidate-r2 的空输出额度中断另存 attempt1，fresh attempt2 的交付没有择优重跑。原评阅协调者亦发生额度中断，recovery 未交付后在用户恢复时新开独立评阅，具体旧评阅结束时间未知。

## 有据发现

- 外观：颜色不直接改变三集叙事，但制作交接和导出仍绑定旧设定，需要核对制作读取的外观依据。
- 知情：移除林夏记得编号行号的前提后，“故意报错→纠正→确认知情”的证据链失去依据，重点涉及第二集、大纲及全季审核。
- 世界规则：透明观察窗与第二集“不透明门”存在直接冲突；看见桌面不自动等于读出行号，需重审试探的信息增量。
- 对白措辞：删除一个指示词没有改变剧情状态，但本集正文、交接、导出与审核仍需复核逐字一致性；不能把动作意思接近当作交付文字同步。
- 伏笔计划：计划改到第三集，第二集仍实际回收，第三集尚缺对应内容。现有候选位置为零；文件级范围仍包含相关正文、连续性、交接与审核。
- 末状态：第一集钥匙留在托盘、双手空着，与第二集开场“仍拿着”冲突；第三集承接的第二集桌面末态未变，不能假定尚未执行的修复会进一步改变它。

## 试点决定

保留文件级权威范围，本轮不增加或推广自动缩小范围的索引。现有位置建议继续仅作为辅助，不能当作完整复核清单。新测量展示了安排阅读优先级的空间，但未记录统一仪表化的实际阅读量、漏检率或维护成本，不能宣称复核量或时间已经减少。

源码检查说明现有位置主要由改变行附近的 CHAR/PROP/LOC、场景及结构化场景引用生成；它不覆盖全部伏笔计划和审核因果。简单增加 F001 字符匹配也不能定位没有该标记的对白、人物知情推断和审核结论。表中“有候选位置”只表示相应产物返回了位置，不能证明位置充分覆盖语义影响。关键产物中没有任何位置建议的清单保存在 summary.json；其中源设定、审核文档等也有现有解析器不支持的种类。

未实现新的索引，因此没有“新索引关键位置零遗漏”或建议复核量减少的验收成绩。将这些成绩明确标为未验证，按协议中“收益或覆盖不足则保留文件级范围”结项，避免把六个固定夹具的人工优先级当成通用自动规则。未来如试点新的定位器，应先扩大带定位证据的夹具并以独立语义覆盖检查和实际阅读成本验收；本轮不改变依赖或状态协议。

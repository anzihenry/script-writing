# M2 对照协议 v1

状态：三例协议试运行后冻结；正式成绩只来自冻结后新上下文运行。

## 样本与边界

24 个原创合成任务，routing/writing/continuity/revision/recovery/handoff 各四例；每类开发、保留各两例。每个任务单独文件目录，执行者不读取 tasks.json、rubric 或其他案例。C01/S01 为开发长文本；C03/S03 为保留长文本，各有十二集、每集明确动作块、对白、首尾状态与60秒估算。它们是人为构造、单场少对白的分场文本，含共享调度格式，不能代表真实制作级长剧或多题材统计样本。

H01/H02 是同源道具替换对照，都在开发集；保留 H03/H04 使用独立场景、声源和状态，避免把仅换道具名的案例拆到两组。其他任务按故事来源隔离。旧评测案例不计入本轮。

本轮任务为文件输入和交付任务，恢复任务包含续写与诊断；不把它们称作完整 CLI 事务恢复。实际项目状态与任务包的执行另由 M3 验证。

## 条件与预算

A：共同任务/来源/CLI说明；B：A 加冻结的类别最小规则；C：A 加完整技能套件，按 entry_rules 按需读取。套件仅为相对链接可用而携带，不要求全读。共同 task 和 source 字节一致；没有不同组独享的用户事实。

每次新建独立上下文，由同一宿主继承模型配置，不覆盖模型或推理设置。提供12次工具调用和通常1500汉字主答复的相同指令预算（完整文件可另附），不联网、不读运行目录以外材料、不启动后续代理。该预算依靠执行者遵守，宿主没有硬性 token/时间限制接口。

开发集12任务 × A/B/C × 2轮，共72次。按任务位置轮换ABC/BCA/CAB，第二轮反转对应顺序。一个执行者结束后才启动下一执行者。只执行准备好的目录 request.md，不把 rubric 或父执行者判断传给执行者。

## 试运行

R01/A、C01/B、S01/C 各一次，用于确认输入读取、文件交付、长文本容量与遥测协议。试运行输出单独存储，不能计入72次成绩。准备阶段修正过部分对白说话者、重新编写两个保留交接案例；这些修正发生于正式冻结前，不根据保留结果改题。试运行失败同样保留。

## 评分与决策

先检查输入未变、必需输出存在、输出哈希。随后把每个任务的来源、冻结 rubric 与各输出副本交给新上下文评阅者；移除运行目录名、condition 和执行元数据，用匿名ID映射。原始答复不改写；若答复自行透露技能使用，盲法可能受限。评分者不访问条件映射，逐条输出 pass/fail/unverified、原输出引用或缺项说明、关键违规和额外发现。

每个任务满足全部 required 且无关键违规才记成功；unverified 不计成功。创作质量由是否实现可见选择、代价、新局面及硬约束判断，不规定唯一剧情。角色不实说法不能自动等同客观穿帮，预置问题与是否应定重大问题分别判断。额外发现有据则记录，不自动算误报，不增加预置分母。

配对报告分组成功数/总数、每类成功数、差异任务、越界修改/虚构证据、读取量中位数及逐运行值。两个重复运行不视为两组独立故事样本；不宣称统计显著性或真实项目稳定准确率。六类小样本的总分不能掩盖关键退化。

按以下预先规则选择后续动作：C 有独有成功的任务则保留其有效规则；B 与C同成功且读取量低则形成精简候选；共同失败按具体错误改方法；没有可辨收益就保留现状，不能为了完成M4强行修改。最多选择三处变更，候选在保留集执行前冻结。

## 记录真实性

记录 prepared/start/finish、执行者ID、输入/输出哈希。实际模型版本、token、费用不能从当前接口取得，记 null；读文件和调用次数是执行者自报，唯一读入字节据自报文件计算，不代表实际累计读取。父执行者 finish 时间包含调度延迟，是墙钟上界，不是模型纯耗时。

共享宿主的技能目录与工具说明仍可见；目录隔离不是OS沙箱。这是该宿主下的增量技能对照，不能宣称完全无先验或跨模型独立。评分者为独立上下文AI，不是真人或独立模型族。

未启动记 not_run；调用平台失败记 infrastructure_failed；任务执行错误记 task_failed。技术重试编号独立且保留原失败。不得因低分重跑挑选最好结果。没有对应实际运行不得填成绩。

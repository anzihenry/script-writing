# 《冷藏室》第一集：先护住

**预计时长：约82秒。** 人名暂定：学徒小周、师傅老陈。
**常驻场景：** 冷藏室内。配电开关、固定货架、墙上温度显示及地漏均为场景设施。
**主要道具（3件）：** 唯一一箱菌种、长柄硬刷、小周的浅色厚棉衣。

### LC-E01-S01｜内·冷藏室·日｜0—20秒

冷风机嗡鸣。地漏堵着，薄薄一层污水贴着地面。

小周把厚棉衣搭在门边货架上，撸起袖子，手伸向配电开关。

**LC-E01-D001 小周：** 先断电。冰化了，才刷得动。

老陈截住他的手，指向架上那只箱子。

**LC-E01-D002 老陈：** 唯一一箱菌种。先护它。

**LC-E01-D003 小周：** 你不是催我今天刷完？

**LC-E01-D004 老陈：** 刷完了，明天拿什么开工？

### LC-E01-S02｜同场连续｜20—45秒

小周试着把菌种箱推到货架深处。箱角碰墙，冷凝水落在箱盖上。

老陈立即把箱子拉回来。

**LC-E01-D005 老陈：** 挪个地方不算护住。停机以后，这里也会暖。

小周看向门边的棉衣。

他取下来，翻看领口，又用掌心抚平衣袖。

**LC-E01-D006 小周：** 昨天刚买的。

老陈伸手接箱子，没有去碰棉衣。

**LC-E01-D007 老陈：** 那就等有保温箱再洗。今天我跟你一起等。

小周低头。污水正漫过鞋底。

### LC-E01-S03｜同场连续｜45—66秒

小周把棉衣铺上货架，抱来菌种箱。湿脏的箱底压下去，浅色衣料立刻洇出灰黑水印。

他停了一瞬，仍把两边衣襟裹紧，衣袖绕过箱角，结结实实打上结。

**LC-E01-D008 小周：** 等着，水也不会自己下去。

他把裹好的箱子挪到远离化霜滴水的上层架。

**LC-E01-D009 小周：** 这样够不够？

老陈摸一遍包裹的缝隙，把露出的一个箱角塞严。

**LC-E01-D010 老陈：** 只能顶一阵。先通地漏，别贪多。

### LC-E01-S04｜同场连续｜66—82秒

小周断电。风机声骤停。

他握住硬刷，老陈却接了过去，俯身把刷头压进地漏边的冰渣。

**LC-E01-D011 老陈：** 你守着箱子，看温度。觉得不行，就叫停。

**LC-E01-D012 小周：** 你还没刷完呢？

**LC-E01-D013 老陈：** 也停。

小周站回开关旁，一只手贴住包着菌种的棉衣。

老陈用力推刷。冰渣松开，积水终于旋着流进地漏。

小周抬眼看温度显示，没有离开开关。

**切黑。**

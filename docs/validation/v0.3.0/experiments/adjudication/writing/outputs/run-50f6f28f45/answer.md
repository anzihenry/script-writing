# 《冷藏室》第一集：先保哪一个

人物暂名：学徒小林、师傅老周。
常驻场景：冷藏室内。主要道具三件：带盖菌种箱、学徒的厚棉服、塑料刮冰板。墙面电源开关、地面排水槽及固定空架属于场景设施。
总时长约80秒；本集仅一场，以下为场内节拍。集场及对白ID保留，不随排版变化。

## E01-S01｜内景·冷藏室·傍晚

### E01-S01-B01｜0—16秒

压缩机低鸣。排水槽口冻着一圈灰冰，脏水漫到小林鞋边。他把刮冰板往冰里一戳，没戳动。

**E01-S01-D001 小林：**断了电，冰一化就能清。我今天得准点走。

他伸手摸向墙上开关。老周横过胳膊挡住。

**E01-S01-D002 老周：**先护住那箱菌种。就剩这一箱。

### E01-S01-B02｜16—34秒

小林望向低架上的菌种箱，又看脚下的水。

**E01-S01-D003 小林：**盖着呢。挪高点不就行了？

**E01-S01-D004 老周：**盖子不保温。没包好，不能停机。

小林把手缩回来，拢紧身上的厚棉服。

**E01-S01-D005 小林：**拿我这个包？新买的。

老周蹲下，试着把刮冰板探进槽口。薄薄一片冰屑落进水里。

**E01-S01-D006 老周：**舍不得，就慢慢刮。刮通了再走。

### E01-S01-B03｜34—59秒

小林盯住那片小得可怜的冰屑。

他猛地拉开拉链，脱下棉服，铺到菌种箱旁。

**E01-S01-D007 小林：**抬一下。

老周抬箱。小林把棉服塞到箱底，雪白的内衬蹭过箱底黑泥。他停了一下，仍把衣角往里扯，两只袖子在箱盖上扎紧。

两人合力把包好的箱子挪上远离积水的空架。小林松手，袖口已经拖湿，滴下两滴黑水。

**E01-S01-D008 老周：**这只能顶一阵。槽通了就送电，别等冰化光。

### E01-S01-B04｜59—80秒

小林穿着薄衫，肩膀开始发抖。他走回开关前，这次先看老周。

老周摸了摸扎紧的袖结，点头。

小林按下开关。机器低鸣骤停。

**E01-S01-D009 小林：**我清槽。你守箱，暖了就叫我。

老周将刮冰板递给他，自己站到菌种箱旁。

小林跪到湿地上，把板尖插进排水槽的冰缝，用身体的重量压下去。

“咔。”一小块灰冰翻起，细细的水流钻进槽口。

**E01-S01-D010 小林：**通一点了。

老周扶着包在棉服里的箱子，没有催他。

切黑。

# EP013 夜钟·13 v1.0
## EP013-SC001 内景／翌日早晨 钟房
角色：商宁、杜衡。约60秒，含操作停顿，未配音实测。

**0—12秒**

钟罩上的“待复测”纸条翘起一角。商宁压平它。杜衡走进钟房，在工具箱旁停下。

杜衡：来交班了。钥匙呢？

商宁低头，手指勾住腰间钥匙，尚未取下。

**12—28秒**

商宁蹲到工具箱前，按合箱盖，将钥匙插入锁孔，转到锁定位；抽出钥匙，再提一下箱盖，确认打不开。

商宁：箱子锁好了。

他站起，将钥匙放进杜衡摊开的掌心。杜衡合拢手指。

**28—46秒**

杜衡看向新绳，脚步刚转，商宁先指了指纸条。

商宁：昨天两声都到了。今天这一次，还没试。

杜衡停住，读完纸条，没有碰绳。

杜衡：知道。待复测接着留。

**46—60秒**

杜衡把钥匙收入衣袋。商宁松开压着纸条的手，退开半步，让出钟前的位置。

商宁：复测完，再记结果。

杜衡抬头看钟面。镜头落回纸条，“待复测”仍清楚可见。两人均未拉绳，切黑。

声音：脚步、锁舌及钥匙轻响；本场无钟声。场末钥匙由杜衡持有，复测与结果登记仍待完成。

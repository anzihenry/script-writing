## EP013-SC001 内景／早晨／钟房

人物：CHAR001 商宁、CHAR002 杜衡。目标：交回钥匙，把待复测事项交清；阻力：交班不等于检修结束。

**0—10秒**

杜衡推门进来，门把上的警示带轻晃。商宁站在工具箱旁，腰间钥匙露在衣外。

杜衡（现场）：“我来接班。”

商宁摸到钥匙，看一眼钟罩上的纸条，先走向工具箱。

**10—25秒**

商宁压实箱盖，将钥匙插入锁孔，转到锁闭位置。拔出钥匙后，提一下箱盖，确认打不开。

杜衡等他验完，伸出手。

**25—40秒**

商宁（现场）：“钥匙交你。明早那次复测，今天还没做。”

商宁把钥匙放进杜衡掌心。杜衡取出衣袋里的空钥匙环，穿入钥匙，收回衣袋。

杜衡（现场）：“知道，先不撤条。”

**40—60秒**

商宁指向钟罩上的纸条，手停在纸边，没有揭下。

商宁（现场）：“临时支撑还不能算修好。再试时，我拉，你看着。”

杜衡走到钟旁，看向新绳，双手仍垂着。

杜衡（现场）：“先把复测准备齐。”

商宁留步。定格在纸条和静止的新绳上。无钟响，切场。

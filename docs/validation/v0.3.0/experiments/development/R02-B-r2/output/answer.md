# 30秒对白估时

来源：`input/source.md`《修鞋铺 v1.0》，对白 EP001-D001、EP001-D002，以及动作预留12秒的说明。

两段对白分别为44字、21字，合计65个汉字（不计角色名、编号和标点）。假设动作12秒与对白不重叠，30秒中剩余18秒用于说话；需达到平均 **3.61字/秒（约217字/分钟）**，且这18秒须包含句间停顿和换人接话。

以下为假设语速下的估算，并非实测：

| 有效语速（含对白间停顿） | 对白用时 | 加动作后的总长 |
|---|---:|---:|
| 3字/秒 | 21.7秒 | 33.7秒 |
| 4字/秒 | 16.2秒 | 28.2秒 |
| 5字/秒 | 13.0秒 | 25.0秒 |

结论：**有条件能放进30秒，但按动作与对白分开计时，空间偏紧。** 有效语速至少需达到3.61字/秒；若按4字/秒计算，则约超出-1.8秒。若擦水等动作可与对白重叠，总时长可相应减少，但输入未明确允许重叠，故未据此扣时。

未验证项：没有演员试读或录音，实际语速、情绪停顿、接话间隔及动作重叠时长均未验证；12秒动作时长直接采用输入预留值。以上仅为估时诊断，未修改原稿。

# 十二集持物连续性审核

结论：盐票实际交接链成立，结尾 EP012-D001 与前集交接及本集画面直接冲突。另有三处动作衔接可补清；以下只提修改建议，未改正文。

## 1. 必修：结尾对白误述盐票持有人

前文 EP011-SC001-B001：“阿岑把盐票从自己口袋取出，夹进红夹子，再把夹子交给罗禾。”EP011-D001：“红夹子连票都给你，明天你去兑。”B003：“罗禾接住红夹子，票的号码仍露在外面。”这已完成票与夹子的交接，不是仅交空夹子。

后文 EP012-D001：“票从昨天起一直在我口袋，谁都没碰过。”但同集 B001：“阿岑摸了摸空口袋，罗禾把红夹子放在秤旁。”B003：“罗禾打开红夹子，露出同一号码的盐票；阿岑的手停在空口袋上。”

判断：按客观持物事实，该句两部分均不成立。最终票在秤旁红夹子中，由罗禾操作；阿岑口袋为空。同一号码也排除了凭空解释成另一张票。原文未明确标记阿岑撒谎或记错，不能自行把矛盾认定为已设计的反转。

最小建议：仅将 EP012-D001 改为“票昨天连红夹子交给你了，现在还在夹子里吧？”保留其余动作和罗禾回应。影响范围：EP012 一句对白及配音；EP011 交接、EP012 揭票镜头均无需调整。如意在表现阿岑说谎，应另行明确表演意图，而非补设画外归还。

## 2. 建议补清：价目板在 EP010 的取放

前文 EP008-SC001-B003：“罗禾把板立在窗边”。后文 EP010-B001：“罗禾提起缝好的袋”，D002 却说“我顶着板，你慢慢拉”，B003 为“阿岑把价目板放回原处”。缺少放袋、取板和解除支撑的动作，属于局部调度缺口，不是已证实的持有人矛盾。

最小建议：在 EP010-D001 后补“罗禾放下袋，从窗边取板顶住门”；B003 补“罗禾松手，阿岑接过板放回窗边”。影响范围：仅 EP010 动作与秒数安排；承接 EP008 板的位置。

## 3. 可补清：收纳和道具入手

- EP003-B001：“把盐票装入透明袋”；B003：“罗禾扣好胸前口袋”。EP005-B003 明确“票仍在罗禾口袋”。归属一致，但装袋至入口袋省略。建议 EP003-B003 在扣口袋前补“将装票的透明袋放入胸前口袋”。仅影响 EP003 动作。
- EP002-B001：“罗禾将盐票挪到灯下，阿岑用尺挡住透光的位置”；D002：“别拿火烤”；B003：“阿岑收起打火机”。打火机此前未展示入手。建议在 B002 对白前补“阿岑掏出打火机，尚未点火”。仅影响 EP002 动作；不增设烤票结果。

## 全程核对与影响边界

EP001 票在桌上、杯压票角；EP002 挪到灯下；EP003 装袋交罗禾保管；EP004 阿岑独处，读便签不构成交接；EP005 明示仍在罗禾口袋；EP006 当面连袋归还阿岑；EP007 无票交接；EP008 阿岑展示后收好，罗禾只拿板；EP009 夹在秤底的是广告，明确未弃票；EP010 无票交接；EP011 连红夹子交罗禾；EP012 夹子落在秤旁并揭出同号票。

因此不能把 EP004 的便签、EP005 的空袋、EP008 的价目板或 EP009 的广告当作盐票交接。EP001 门边空盐袋与 EP005 罗禾自带空袋也不应强认同一物件。EP006 后透明袋的去向未逐次说明，是包装调度留白，不足以推翻票的持有人链。除上述项目，其余未见明确持物冲突。

# 《旧照相馆》｜第01集《押在这里》

时长约82秒。单一常驻场景：旧照相馆柜台内外，日。
人物：店主、顾客（均以身份称呼，暂不命名）。主角为店主。
主要道具共三件：一条底片、一叠现金、写有“房租”的信封。柜台为固定布景。

## E01-S01｜内·旧照相馆·日

### E01-S01-B01｜0—18秒

顾客捏着底片两端，退离柜台。店主伸出的手停在半空。

**E01-S01-D001 店主：** 底片还我。你刚才把折痕指给我了，我能修。

**E01-S01-D002 顾客：** 先看修好的，再付钱。

**E01-S01-D003 店主：** 一百定金，出片再补两百。

顾客把底片移到身侧。店主绕出半步，又站住。

### E01-S01-B02｜18—37秒

**E01-S01-D004 顾客：** 我爸就剩这张。钱付了，修坏了，你退钱就完了？

店主收回手。

**E01-S01-D005 店主：** 折痕压着眼睛。能修到什么样，得放大看。

**E01-S01-D006 顾客：** 那你刚才说“能修”？

店主看着顾客，不再接话。顾客转身朝出口走一步。

### E01-S01-B03｜37—64秒

**E01-S01-D007 店主：** 等等。

店主从柜台下拿出“房租”信封，抽出现金，数出三张百元钞票。信封里只剩一张。

他先把三张往顾客那边推，指尖却迟迟没有离开。

**E01-S01-D008 顾客：** 你给我钱？

**E01-S01-D009 店主：** 押你这儿。底片留下，明天你来看。不满意，这三百你拿走，底片也还你。

顾客看一眼信封。

**E01-S01-D010 顾客：** 房租呢？

店主把现金彻底推出手边。

**E01-S01-D011 店主：** 先算我欠的。

### E01-S01-B04｜64—82秒

顾客拿起三百元，装进口袋。底片仍捏在手里。

店主把只剩一张钞票的信封压平，放回柜台下。再抬头时，顾客已将底片平放在柜台上。

**E01-S01-D012 顾客：** 明天几点？

**E01-S01-D013 店主：** 下午五点。

**E01-S01-D014 顾客：** 我四点来。修成什么样，我在这儿等。

店主点头，小心托起底片两端，对着店里的光。

顾客没有立刻走，往柜台前挪近一步。两人隔着底片，看见同一道折痕。

切黑。

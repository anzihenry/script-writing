第十三集首场

EP013-SC001　内景／次日早晨／钟房
人物：商宁、杜衡。约60秒，含操作停顿，未实测。

【0—12秒】
杜衡进门。商宁站在工具箱旁，腰间钥匙随转身轻碰箱沿。钟罩上的“待复测”纸条仍在。

杜衡：来交班了。

商宁看一眼纸条，手停在腰间。

商宁：钥匙交你。昨天那两声响过，今天这次还没试。

【12—30秒】
商宁俯身压合箱盖，捏住锁扣轻提，确认扣住。她从腰间取下钥匙，递向杜衡；等他握稳，才松手。

杜衡把钥匙收进衣袋，拍一下袋口。

杜衡：收到了。先接箱子。

【30—46秒】
商宁走到钟罩前，指尖停在纸条旁，没有揭下。

商宁：这张先留着。说好今早再试一次，等看完结果再记。

杜衡走近，看清“待复测”三个字。

杜衡：好。没试，就还挂着。

【46—60秒】
商宁退开半步，让出绳前的位置。杜衡站到新绳旁，抬头看钟面，手没有拉绳。

商宁：上回是等分针越过刻度。

杜衡点头。两人一起看着分针。镜头落回纸条，钥匙已在杜衡衣袋里；无钟声，切黑。

## EP013-SC001 内景／早晨 钟房

人物：CHAR001 商宁、CHAR002 杜衡。目标：交还钥匙，交清尚未完成的复测；阻力：交班不能被误认成修复验收。以下对白均为现场。

**0—12秒｜EP013-SC001-B001**

门开。门把上的警示带随之晃动。杜衡进来，停在工具箱旁。商宁腰间钥匙轻碰箱沿。

杜衡（EP013-D001）：我来接班。钥匙呢？

商宁（EP013-D002）：先看箱子。

**12—27秒｜EP013-SC001-B002**

商宁蹲下，取下钥匙插入锁孔，将锁扣锁定，拔出钥匙，再提一下箱盖。箱盖不开。杜衡看清，摊开手。

商宁把钥匙放进他掌心。杜衡从衣袋取出空钥匙环，将钥匙穿上，收回衣袋。

商宁（EP013-D003）：箱子锁好了。钥匙交回。

**27—45秒｜EP013-SC001-B003**

商宁起身，指向钟罩上的纸条。杜衡顺着她的手看过去。

商宁（EP013-D004）：昨天两声都到了。今天这一次，还没试。

杜衡（EP013-D005）：那这张先留着。

商宁（EP013-D006）：嗯。试完再记。

**45—60秒｜EP013-SC001-B004**

杜衡走到新绳旁，手伸向绳端，停住，抬眼看分针。商宁退开半步，给他让出位置。

杜衡（EP013-D007）：等分针过去。

商宁点头。镜头落在仍贴牢的“待复测”纸条，再带到两人等待的手。绳未拉动，无钟声。切。

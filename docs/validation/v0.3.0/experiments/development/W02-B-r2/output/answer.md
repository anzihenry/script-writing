# 《冷藏室》第一集：先关哪一道

本场目标：学徒小林想断电，把门槛积水和污泥一次清净，结束当班。
阻力：门封夹着污泥，门关不严；师傅老周守着唯一一箱菌种，不肯让仍在回温的冷藏室停机。
可见选择：小林放弃断电快洗，撕开自己新工服的袖口，用它清理门封，承担工服损坏和继续留班的代价。
结果：门终于封住，菌种留在运转的冷藏室；师傅把守箱的位置交给小林，自己接手清理。

人物姓名暂定。全集仅小林、老周；唯一场景为冷藏室内门口。主要道具三件：菌种箱、新工服、墙上固定电闸。门、门封及货架为场景固定设施。无其他人物或画外解围。

## E01-S01｜冷藏室内·夜

### E01-S01-B01｜约0–20秒

门关到最后一寸，又弹开。压缩机持续运转。门槛积着脏水。

小林穿着新工服，抬手碰电闸。老周抱着菌种箱，挡在闸前。

**E01-S01-D001 小林：** 断了吧。化开，一冲就净。我能走，你也能走。

**E01-S01-D002 老周：** 门一晚上没关严。这箱还没冷下来。

**E01-S01-D003 小林：** 那你先挪出去。

**E01-S01-D004 老周：** 就剩这一箱。你给我找个冷地方。

小林望向门外，没动。

### E01-S01-B02｜约20–42秒

老周用肩顶门。门封卷起一角，夹着黑泥，仍有一道缝。

小林蹲下，手指抠出一点泥，粘在指腹。他抬起袖口，停住，把干净袖子往后缩。

**E01-S01-D005 小林：** 今天才领的。弄坏了，得自己买。

**E01-S01-D006 老周：** 放着，我抱完这箱再弄。

小林看着他被箱沿压红的手，又看一眼电闸。

**E01-S01-D007 小林：** 你别松。我来。

### E01-S01-B03｜约42–65秒

小林脱下工服。袖口太厚，塞不进门封折缝。

他抓住袖口开衩，用力撕开一截，裹住手指，把黑泥一点点带出来。新衣袖拖过门槛，吸满污水。

老周往电闸方向让开半步。

**E01-S01-D008 老周：** 还断吗？

**E01-S01-D009 小林：** 不断。先让它冷。我晚点走。

小林沿门封擦完最后一段，拉直翻卷的胶条，慢慢合门。这一次，门贴住了。

### E01-S01-B04｜约65–82秒

两人静候两秒。门没有再弹开。

老周把菌种箱放到里侧货架上，松开一直托着箱底的手。小林伸手扶稳箱子。

老周蹲下，从小林手里接过湿透的工服，擦门槛剩下的水。

**E01-S01-D010 小林：** 你不是只管菌种吗？

**E01-S01-D011 老周：** 现在你管。门缝别再开了。

小林站到箱子旁，低头看一眼撕裂的袖口，再把掌心贴在门边，确认没有漏缝。

切黑。

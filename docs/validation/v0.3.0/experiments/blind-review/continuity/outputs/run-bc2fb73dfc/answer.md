## 需处理：结尾的持物断言不成立

**前文证据**：EP006-SC001-B001：“罗禾把装有盐票的透明袋交还阿岑，阿岑当面收入口袋。”这只能证明第6集时收回，不能支持此后始终持有。

更近的EP011-SC001-B001：“阿岑把盐票从自己口袋取出，夹进红夹子，再把夹子交给罗禾。”EP011-D001进一步确认：“红夹子连票都给你，明天你去兑。”

**后文冲突**：EP012-D001：“票从昨天起一直在我口袋，谁都没碰过。”但同集B001是“阿岑摸了摸空口袋，罗禾把红夹子放在秤旁”；B003是“罗禾打开红夹子，露出同一号码的盐票；阿岑的手停在空口袋上。”

**判断**：盐票位置连续，错误在阿岑的断言；他亲手交出，罗禾亲手接过，两人都经历了交接。“一直在我口袋”“谁都没碰过”均与动作不符。同号码排除了凭空解释为另一张票的依据。文本未说明这是故意否认、记忆错误还是台词失误，意图未知。

**最小建议**：若台词意在陈述事实，仅将EP012-D001改为：“票昨天交给你了，一直夹着，没拆过吧？”保留疑问，避免把罗禾此前“不拆开”的承诺写成未经展示的事实。若意在表现阿岑否认交接，可保留原句，补一句回应或反应，明确这是人物失实说法。

**影响范围**：直接涉及EP012-D001及必要时相邻反应；以第11集交接为依据，无须倒改第6、8集或取消第11集交接。其他物件未发现足以成立的硬性持物矛盾；第10集价目板的拿取衔接略省略，不足以另报断链。

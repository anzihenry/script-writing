# 《旧照相馆》第一集：先看一眼

本场目标：店主想从顾客手里取回底片，按“先付修复费、再交成片”的规矩完成交易。
阻力：顾客坚持看清修复效果才付款，攥住底片不交。
可见选择：店主主动翻开被自己遮住的成片，承认修坏了，撕掉收费单，承担免费重做的成本。
结果：顾客交回底片，但保留成片作对照，验收权转到顾客手中。

人物（暂定名）：店主老周，顾客林岚。老周为本集主角。
常驻场景：旧照相馆内，柜台前。主要道具仅三件：一条底片、一张修复成片、一张收费单。柜台为固定布景。
总时长估算：约80秒；含动作与停顿，未经实测。

## J01-C01｜内·旧照相馆·日

### J01-C01-B01｜约0—14秒

林岚站在柜台外，捏着底片边缘。老周伸手去接。她把底片收回胸前。

**J01-C01-D001 老周：** 底片先给我，别碰着画面。

**J01-C01-D002 林岚：** 照片让我看一眼。

老周的另一只手压着反扣的成片，将收费单推到她面前。

**J01-C01-D003 老周：** 修复费二百。结了再交片。

### J01-C01-B02｜约14—29秒

**J01-C01-D004 林岚：** 我还没看见，你就让我先付？

**J01-C01-D005 老周：** 做了两晚上，总得收钱。

林岚看着他压住照片的手。

**J01-C01-D006 林岚：** 那你翻过来。

老周没动。她转身半步，底片仍攥在手里。

### J01-C01-B03｜约29—46秒

**J01-C01-D007 老周：** 等一下。

他松开手，把成片翻正，推到灯下。

照片上，女子脸颊的一道浅疤被抹掉了。

**J01-C01-D008 林岚：** 她脸上那道疤呢？

**J01-C01-D009 老周：** 我当划痕修掉了。

**J01-C01-D010 林岚：** 那是我妈。不是脏东西。

老周低头看照片，手指停在那片过分平整的脸颊旁。

### J01-C01-B04｜约46—65秒

他拿起收费单，看了一眼“200”，从中间缓缓撕开，放在自己这一侧。

**J01-C01-D011 老周：** 这张不收钱。底片留下，我重新做。

**J01-C01-D012 林岚：** 重做再收二百？

**J01-C01-D013 老周：** 不收。算我这两晚上白干。

他将空着的手放在柜台上，不再伸向她。

### J01-C01-B05｜约65—80秒

林岚把成片拉到自己面前，随后将底片放入老周手中。

**J01-C01-D014 林岚：** 这张我拿着。下次对着看，别又替她改了。

老周接稳底片。

**J01-C01-D015 老周：** 下次你先看。

林岚拿起成片。老周将底片平放，拨开旁边撕断的收费单，俯身辨认底片上那道细小的疤。

切黑。

# 《冷藏室》EP001《不断》

G3 单集正文｜v1.0｜draft  
依据：input/request.md、brief.md。暂定主角为学徒阿禾（CHAR001），师傅老周（CHAR002）；时间为冬夜。唯一场景 LOC001：冷藏室内。主要道具三件：菌种箱 PROP001、阿禾的新棉衣 PROP002、墙面电闸 PROP003（连固定设施也计入预算）。其余仅固定墙、地面、货架，无画外人物。

本集变化：阿禾为赶车要断电化霜，最终主动留下，改做不断电的局部清理；师傅由拦阻者变为听她安排的搭手。

## EP001-SC001｜内·冷藏室·夜

入场：压缩机轰鸣，地上有一小片积水。唯一一箱菌种放在低层货架上。阿禾已穿好新棉衣，手搭电闸；老周挡在箱前。

### 分段动作与时长

以下时间块依次衔接，动作与对应对白并行。

**EP001-SC001-B001｜0–13秒**  
阿禾抬起电闸盖，拇指顶住开关。D001。老周一掌压住盖边，另一只手扶着菌种箱。D002。阿禾的拇指没有松。

**EP001-SC001-B002｜13–27秒**  
D003、D004。阿禾低头：积水正沿地面伸向低层货架。箱底边缘已湿。她指给老周看，D005。老周蹲下，把箱抱离底板，D006。

**EP001-SC001-B003｜27–45秒**  
阿禾望向门，跨出半步。停两秒。她转回来，亲手合上电闸盖；轰鸣不断。她脱下棉衣，露出薄工作服，D007。老周抬箱。阿禾把干燥的衣里压上湿底板，手掌推过去，衣里立刻洇黑。D008。她按得更实，没有抽回。

**EP001-SC001-B004｜45–61秒**  
D009。老周将箱稳稳放在干燥的上层固定货架。阿禾跪下，用已脏的棉衣拢住地上积水。她的肩膀开始发抖。老周看门，再看她，D010。她停手，抬眼说D011。

**EP001-SC001-B005｜61–80秒**  
阿禾继续擦水，D012。老周不再催她，蹲到另一边，抓住棉衣另一端。D013。两人将水一点点拢离货架。最后定在上层的菌种箱，再移到紧闭的电闸盖；压缩机声持续。切黑。

出场：电未断，菌种箱已移离积水；整体化霜延后，两人开始局部清理。阿禾错过末班车，新衣被污水浸透，并承担冷中留下的代价。

计时：总估算80秒，可表演区间76–88秒，不另加片头尾；对白按约3–4字/秒、轮流相加，余量留给转身、脱衣、搬箱和停顿，未实际朗读。自查覆盖两人、单场景、三道具、选择因果及持物连续性；未做实拍验证。湿衣前后需保持同一污痕。后续若续写，应从“仍未断电、两人正在清水”接起。

# 《旧照相馆》EP001：先退钱

G3｜v1.0｜draft。依据本次 request.md、brief.md 创作。

暂定设定：店主老周（CHAR001，主角）上次把照片洗花，顾客小林（CHAR002）带底片回来交涉。老周想取回底片重洗，却仍要求预付款。

仅用旧照相馆柜台区 LOC001；主要道具三件：底片 PROP001、洗花的照片 PROP002、一张百元纸币 PROP003。柜台及翻板为固定布景。两人便装，全程不换装。

## EP001-SC001｜内·旧照相馆·日｜约80秒

入场：小林拿着底片与照片；老周隔柜伸手。目标是拿回底片重洗，阻力是顾客不再信任先付款的规矩。

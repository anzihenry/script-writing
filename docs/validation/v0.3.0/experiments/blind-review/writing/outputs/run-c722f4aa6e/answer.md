v1.0｜draft｜G3单集正文。来源：input/request.md、brief.md。
暂定：学徒小禾（CHAR001，主角）、师傅老陈（CHAR002）；夜，冷藏室LOC001。主要道具仅三件：带盖菌种保温箱PROP001、墙上电闸PROP002、小禾的新外套PROP003；固定搁架、地漏属场景。无片头尾，估算80秒。
本集变化：小禾从求快收工，到毁掉新衣、留下清理；师傅从拦她动电闸，到按她的安排配合。

两人均在室内。箱子放在地上，融水正向箱底漫来。小禾穿着挺括外套，伸手够电闸。老陈蹲在箱旁。

| EP001-D002 | 老陈 | 等等。先把这一箱护好，只剩它了。 |
| EP001-D003 | 小禾 | 那您倒是松手，让我搬。 |

| 时间块ID | 估时 | 动作、对白与声音 |

| EP001-SC001-B002 | 13秒 | 小禾蹲下说D003。老陈松开箱侧，改托箱底；二人合力把箱子搬上固定搁架。小禾拧紧箱盖，老陈逐边按实。搬箱声后留两秒静默。 |

出场：箱已离开积水，但地漏仍被黑色污泥堵住。小禾尚未断电。

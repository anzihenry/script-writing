# 《旧照相馆》第一集：先退钱

**本场目标：**店主周成取回顾客手里的底片，补洗照片，留住这单生意。
**阻力：**顾客林禾已付过一次钱，拿到的照片却裁掉了母亲半张脸；她拒绝先付补洗费，也不肯再交底片。
**可见选择：**周成将已经收下的钱全数退还，让林禾先收好，再空手索要底片；他承担前次冲洗损失，并放弃补洗预付款。
**结果：**林禾留下底片，却把验收权握在自己手里。交易从店主先收款，变为顾客验货后决定是否付款。

人物姓名暂定。仅周成、林禾两人。常驻场景：旧照相馆前厅。主要道具三件：一条底片、一张洗坏的照片、两张百元现金。柜台为固定陈设。

## E01-S01｜内·旧照相馆前厅·日

### E01-S01-B01｜约0–18秒

林禾将照片推到柜台中央。照片边缘，母亲的脸只剩一半。

周成伸手。林禾立即把底片收回胸前。

**E01-S01-D001 周成：**底片给我。我重新洗，脸能留全。

**E01-S01-D002 林禾：**这回多少钱？

**E01-S01-D003 周成：**补八十。先付，我才好开工。

**E01-S01-D004 林禾：**上回那两百，也是这么说的。

### E01-S01-B02｜约18–37秒

周成把照片转向自己，指腹压住被裁断的边缘。

**E01-S01-D005 周成：**这张没洗好，我认。八十只收材料钱。

**E01-S01-D006 林禾：**材料用了，照片我能摆吗？

周成手指缩回来。

**E01-S01-D007 周成：**你拿走底片，我连补救都做不了。

**E01-S01-D008 林禾：**那是我的底片。

林禾转身。周成绕出柜台半步，停住，让开通往门口的位置。

### E01-S01-B03｜约37–60秒

**E01-S01-D009 周成：**等一下。

周成从衣袋取出两张百元现金，放到柜台上，推过照片。

**E01-S01-D010 周成：**上回的钱。退你。

林禾没动。

**E01-S01-D011 林禾：**拿底片换？

周成撤回手，退到柜台后。

**E01-S01-D012 周成：**你先收好。

林禾回来，数清两张钱，装进口袋。周成看着钱消失，抿了一下嘴。

这才摊开空手。

**E01-S01-D013 周成：**再让我洗一次。不先收钱。

### E01-S01-B04｜约60–80秒

**E01-S01-D014 林禾：**还是这样呢？

**E01-S01-D015 周成：**你不付。

林禾看了他一会儿，将底片平放在柜台上，手指仍压着一端。

**E01-S01-D016 林禾：**别替我裁。边上空着也留着。

**E01-S01-D017 周成：**留着。

林禾松手，却没有离开。她将洗坏的照片转回周成面前。

周成拿起底片，比对照片上被切掉的地方。林禾在柜台另一侧等着。

**切黑。**

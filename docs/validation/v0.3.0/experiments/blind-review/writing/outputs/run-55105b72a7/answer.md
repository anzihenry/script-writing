# 《冷藏室》第一集：先保哪一个

**本场目标：**学徒要立即断电清理积水，早点收工。  
**阻力：**师傅坚持先安置唯一一箱菌种；室内没有干燥落脚处。  
**可见选择：**学徒脱下唯一的外套包住菌种箱，抱箱守在原地，把清理工具交给师傅；他失去保暖，也放弃立即离开的机会。  
**结果：**师傅接手清理，并让学徒决定何时恢复供电。学徒从抢着结束工作，变成负责守住菌种的人。

人物暂名：学徒小齐、师傅老陈。全集仅两人。  
常驻场景：冷藏室内。主要道具三件：菌种箱、外套、地刮。电源开关为墙面固定设施。  
总时长约80秒；以下为创作估时，非拍摄实测。

---

## E01-S01｜内·冷藏室·晚

### E01-S01-B01｜约0—18秒

地面积水漫到门边。小齐推地刮，刮过的水又缓缓回流。他把地刮靠墙，伸手去按墙上开关。

**E01-S01-D001 小齐：**断了电，我把这点水弄完就走。

老陈托起湿地上的纸箱。箱底软了一角，他立即换手兜住。

**E01-S01-D002 老陈：**先接这个。

**E01-S01-D003 小齐：**搁门边不就行了？

老陈看向门边。小齐顺着看过去——水已经淹过自己鞋底。

### E01-S01-B02｜约18—40秒

小齐接住箱子，试着往墙脚放。老陈没有松手。

**E01-S01-D004 老陈：**就剩这一箱。底一破，你拿什么接？

小齐收回下放的动作，看一眼开着的门，再看自己的外套。

**E01-S01-D005 小齐：**我抱着，你清？

**E01-S01-D006 老陈：**你不是急着走？

小齐把箱子暂交回去，拉开外套，脱下。老陈托箱；小齐把衣服绕过箱底，拢紧两只袖子，重新抱住。

**E01-S01-D007 小齐：**刮子在你右边。

### E01-S01-B03｜约40—62秒

老陈取地刮，先清出小齐脚边的一块干地。小齐抱箱挪过去，薄衣下的肩膀打了个颤。

老陈伸手要替他托箱。小齐把箱子抬高，避开那只手，用下巴指向水最深的地方。

**E01-S01-D008 小齐：**那边还没通。你接了，谁弄？

老陈收手，走向开关，停住。

**E01-S01-D009 老陈：**抱稳了？

小齐把湿掉的外套下摆往怀里收。

**E01-S01-D010 小齐：**稳了。关吧。

制冷声停下。照明仍亮。老陈开始推水。

### E01-S01-B04｜约62—80秒

安静里，只剩地刮摩擦声。小齐想换一下抱箱的手，箱底微微下坠，他立刻用膝盖顶住，再牢牢兜回怀里。

老陈看见，加快了动作。

**E01-S01-D011 老陈：**待会儿哪儿能放，你来挑。

小齐望向刚清出来的干地，又看箱底。

**E01-S01-D012 小齐：**先别放。把我站的这块再弄干一点。

老陈依言转过地刮。小齐站着没动，双臂把箱子又往上送了一寸。

切黑。

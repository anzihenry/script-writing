# 《旧照相馆》第一集：先赔

人物：店主老周（主角）、顾客小林；姓名暂定。
常驻场景：旧照相馆内，柜台至门口。主要道具三件：一条底片、一张样片、两张百元钞票（合计一组现金）。柜台为固定布景。
预计时长：80秒。以下集场、对白ID固定，修订时保留。

### J01-C01｜内·旧照相馆·日｜0—18秒（18秒）

小林将样片推过柜台。一道白痕横穿照片里的人脸。

老周伸手去取他指间的底片。小林收手，底片藏到身后。

**J01-D001 老周：** 底片给我，重新扫，放大。八十，先付。

**J01-D002 小林：** 上次也是先付。

小林用指甲点住白痕。老周的手停在半空。

### J01-C02｜同场连续｜18—39秒（21秒）

**J01-D003 老周：** 先让我看看，是底片伤了，还是——

小林把底片举向窗光，找到对应的一格，只准他隔着看。

老周凑近。细长划痕随着底片的转动，亮了一下。

**J01-D004 小林：** 你交给我那天就有。我问，你说放大就好了。

老周退开，低头看样片。

**J01-D005 老周：** ……这道痕，放大也去不掉。

小林将样片抽回，转身走向门口。

### J01-C03｜同场连续｜39—63秒（24秒）

**J01-D006 老周：** 等一下。

小林停步，仍攥着底片。

老周掏出两张百元钞票，压平在柜台上。他的手指压着钱角，迟迟没松。

**J01-D007 小林：** 拿钱换底片？

老周看看底片，又看看自己指下的钱。他松手，把两张钱推过柜台，收回双手。

**J01-D008 老周：** 洗坏的，赔你。底片你带走。

小林回来，拿钱，折好，放进口袋。

老周没有再伸手。

### J01-C04｜同场连续｜63—80秒（17秒）

小林走到门边，低头看看样片里被划过的脸。

**J01-D009 小林：** 剩下没划的，还能放大吗？

**J01-D010 老周：** 能。先让你看清楚，再收钱。

小林走回来，把底片放在柜台上。一端仍压在他指下。

**J01-D011 小林：** 我就在这儿看着。

老周点头，摊开掌心，等着。

小林终于松开。老周只捏住底片两侧，抬向窗光；小林挪到他身旁，一起看。

切黑。

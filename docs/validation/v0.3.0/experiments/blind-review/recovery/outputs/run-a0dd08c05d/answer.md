# EP013 夜钟·13 v1.0
## EP013-SC001 内景／晨 钟房
角色：商宁、杜衡。约60秒，含动作停顿，未配音实测。

**0—12秒**

门把上的警示带轻晃。杜衡推门进来，看向钟罩上的“待复测”。商宁站在工具箱旁，钥匙仍挂腰间。

杜衡：来换你。早上试了吗？

商宁：还没有。昨晚两声，今天这次还欠着。

**12—30秒**

商宁蹲下，扶稳箱盖，将腰间钥匙取下插进锁孔，转动后拔出。她提一下箱盖，盖子未起。杜衡看完，伸出手。

商宁：箱子锁好了。钥匙交给你。

钥匙落入杜衡掌心。他握住，收进衣袋。

**30—47秒**

商宁走到钟旁，指给他看罩上的纸条，没有揭下。

商宁：这张先留着。等分针越过刻度，再试。

杜衡看一眼钟面，伸向绳端的手停住。

杜衡：响完等余音停。试过了，再记结果。

**47—60秒**

商宁让开绳前的位置，仍站在一旁。杜衡站定，两人抬头看分针。镜头落回“待复测”纸条，再移至尚未被拉动的新绳。

只闻衣料和脚步声。切黑。

场末：钥匙已在画面内交给杜衡，工具箱锁闭；待复测纸条保留，复测尚未开始。

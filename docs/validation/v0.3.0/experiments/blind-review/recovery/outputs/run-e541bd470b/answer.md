第十三集首场

EP013-SC001　内景／翌晨　钟房
角色：商宁、杜衡。约60秒，含操作与停顿，未配音实测。

| 时间 | 动作与对白 |
| --- | --- |
| 0—12秒 | 杜衡进门，在钟罩前停下，看见“待复测”纸条。商宁站在工具箱旁，腰间钥匙清楚入画。杜衡：“我来换班。还没再试？”商宁：“没有。昨晚两声，今天还得复测。” |
| 12—28秒 | 商宁从腰间取下钥匙，俯身检查工具箱锁扣，用钥匙将锁置于锁闭位置，拔出钥匙，再提一下箱盖；箱盖未开。杜衡看着她的动作，伸出手。 |
| 28—40秒 | 商宁把钥匙放进杜衡掌中，等他握住才松手。商宁：“箱子锁好了，钥匙交你。”杜衡从衣袋取出空钥匙环，把钥匙穿上，收回衣袋。 |
| 40—53秒 | 商宁指向钟罩上的纸条，不揭下。商宁：“复测做完再记结果。这张先留着。”杜衡看过纸条，点头：“先复测，再记。” |
| 53—60秒 | 两人走到钟旁。商宁停在新绳边，手没有拉动绳端；杜衡抬眼看钟面。镜头落回仍贴着的“待复测”纸条，切黑。 |

声音：脚步、锁扣与钥匙环碰响；本场无钟响。场末钥匙已当面交给杜衡，复测仍待进行。

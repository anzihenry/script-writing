# M3 任务上下文包与恢复对照

评测完成日期：2026-11-08；工程结项日期：2026-11-09（Asia/Shanghai）。24次正式恢复运行、六类独立匿名初评、5项独立复核全部完成。任务包以显式可选命令提供，不改变原有next或自动执行创作、登记、审核和交接。

## 工程结果

新增 `context PROJECT --scope S --stage G --output PATH [--task TEXT]` 与 `verify-context PROJECT --file PATH`，操作说明在技能的references/operations.md。生成器保存完整来源副本、当前/登记哈希、阶段入口及按需依赖、检查点变化、未决问题、完成命令和未知状态。当前目标及已有前置不会因缺少输出而被排除；G3索引截止前集，G4/G5可包含本集。用户任务保存为数据，authorization仍为unspecified，命令不推定授权。

项目只读、输出必须在项目外且不存在，失败不留部分目标。生成退出0/1分别表示无/有结构阻塞；退出1仍提供诊断包。验证退出0仅表示来源与副本新鲜，不消除包中已有阻塞；来源/规则/副本变化返回1，非法包或路径返回2。manifest.sha256用于意外改动检查，不是签名或批准凭证。

复用既有依赖、gate、状态索引与检查点语义，保留旧命令及project.json 1.0。原next/status在3/30/100集测量中仍各执行一次inspect；新旧示例按预期通过，旧散文的index/parity继续UNVERIFIED。测试覆盖只读、缺目标/来源、过期、旧格式、未决问题、前集与未来检查点、覆盖/越界拒绝、原子失败、来源与包内副本变化及评测复算。

初版在3次运行后，工程检查发现新集恢复遗漏前集检查点，停止该轮并保留为 [预检v1](pilot-v1/README.md)。修复检查点选择、补回归测试后重新冻结完整24次正式矩阵；未根据输出或得分选择重跑。预检不计正式分母。

## 初评、复核与证据边界

初评baseline/context分别10/12和9/12。local_revision四项因匿名包未提供项目输入前后对照，将“未写回项目”判未验证；另有一项normal把“正文和台账缺失”视为关键违规，因为目录中仍有未填模板。

新的独立评阅者收到匿名的完整前后项目哈希、实际收集的运行后副本、原任务、原稿/交付及冻结标准。四项修订改判通过，明确仅证明结束时字节未变，不能证明从未短暂写入；normal撤销关键违规，因为任务所需已完成/已登记产物确实缺失，同时保留措辞应区分未填模板与物理文件缺失的意见。原 [初评](initial-grades.json) 与 [复核](adjudication/adjudication.json) 分别保存，最终汇总绑定原判和复核哈希，不改原交付。

四次N04候选稿仅将D002“我腰上”改为“你腰上”，其余字节一致；这项机械检查不代替语义判断。匿名评分故意不提供execution.json，一些额外发现因此认为所链接的执行记录不可核验；完整运行归档实际均有该文件，这属于评分视图限制，不是执行者漏交。

初评使用六个独立上下文，另一个独立上下文复核；条件映射隐藏但答复可能透露使用任务包，因此是部分盲化，不是人类或不同模型族评审。normal的8处非连续引用经技术修正，原版保留，全部非quote字段未变。local_revision首位评阅者额度中断且未交评分，授权恢复后以新上下文评阅。

四个正式运行断点保留：N01-context-r1无输出额度中断；N05-baseline-r1停在starting且启动状态未知；N02-baseline-r2留下部分read-audit；N05-context-r2无输出额度中断。均在用户明确恢复后启动新尝试，旧证据保留，完成项不重跑。没有因低分挑选输出。

本实验只在output交付修改候选或诊断，没有验证代理对真实项目执行登记/修订写回，也没有真实配音、制作接收或生产审批。只读边界由前后字节核验支持，不宣称OS级隔离或连续系统调用审计。

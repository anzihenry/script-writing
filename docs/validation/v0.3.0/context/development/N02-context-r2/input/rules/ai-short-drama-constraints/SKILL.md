# G0 立项-5 规格与制作预算

## 输入与范围

需求、概念、已有资产及用户硬限制。

先读[共同约定](../ai-short-drama-writing/references/common.md)，再按需读流程 G0 与模板第1节。入口：[标准](../ai-short-drama-writing/references/standards.md)、[流程](../ai-short-drama-writing/references/workflow.md)、[模板](../ai-short-drama-writing/assets/templates.md)。

## 执行

1. 明确集数、时长、语言、画面形态、画幅及片头片尾计时口径；未定值注明假设。
2. 分别预算常驻/临时角色、地点、服装变体、道具与特殊场面，不虚构模型测试结果。
3. 核对概念可否落入预算，提出保留叙事作用的替代；收拢简报中的未决项。

## 产物与写入边界

brief.md 的规格与预算：维度、目标/上限、硬/软约束、依据、冲突、替代方案。

默认在已有项目文件的对应章节维护；无文件时可先交付同结构文本。只修改上述产物及用户明确要求的必要关联内容，其他问题列影响与返工建议。每次标明输入版本、输出版本、覆盖范围和未决项。

## 验收与返工

规格有口径，资产预算可核对；冲突未静默消失。

不可同时满足的硬规格退回需求选择，不能暗中改时长或集数。

本步骤完成后停止，除非用户已要求后续步骤。可通过[阶段入口](../ai-short-drama-brief/SKILL.md)衔接；直接调用无需先执行阶段入口。共享资料与父入口需要保留相邻目录。

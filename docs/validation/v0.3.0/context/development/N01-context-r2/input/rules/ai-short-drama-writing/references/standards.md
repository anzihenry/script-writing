# 写作与审核标准

本文件的数值、分级与表格是内部工作约定，可由项目覆盖。不存在对所有题材都成立的“每几秒必须反转”规则。

## 一、故事与人物

- 一句话故事包含主角、目标、核心阻力与失败代价；总纲要写到结局，不能全用悬念替代答案。
- 主角通过选择推动关键变化。巧合可以开启困境，不宜无铺垫地解决核心冲突。
- 每集明确“开始局面 → 行动与阻力 → 结果 → 新局面”。钩子可以是悬念、情感兑现、喜剧落点或新目标；完整短篇可以闭合结尾。
- 反转改变观众对证据、关系或目标的理解。指出此前铺垫和重新解释的事实，不能只是突然增加身份或规则。
- 人物有欲望、恐惧、底线、关系与说话习惯。对白体现当前目的和人物差异，避免所有人都解释观众已知信息。
- 世界规则明确适用条件、代价和限制；新增规则不得只为解围且不交代原因。
- 改编区分原作事实与新增桥段，检查合并人物后是否改变动机、知情范围和因果。

## 二、场次与对白

每场记录时间/内外景/地点、出场人物、入场状态、目标、阻力、动作与对白、结果、出场状态。只保留与本场相关的状态，不强迫填无用细节。

“她很绝望”应落到表演证据，例如“她按下最后一个号码，听见空号提示，把写满电话的纸折起”；“他知道了真相”应写出获取证据的行动。心理旁白可用于明确选择的风格，但不能拿它掩盖缺失的戏剧行动。

对白标明角色 ID、方式（现场/画外/内心/旁白）、必要情绪和动作关系。为角色不同口吻服务的碎句、停顿、口头语可保留；避免把每句台词都写成演技指令。

画面必须读清的证据文字使用独立 `screen_text` 项，注明展示目的、阅读预算和后期叠字需求；不要假定生成模型会准确输出中文。不要将全部字幕当作必须由画面生成的文字。

## 三、时长核算

建立按顺序排列、互不重叠的时间块：每块内标记同时发生的对白、动作和声音。串行块相加；同一块的并行动作/对白以较长者为基础，另计不能重叠的停顿。片头、片尾、回顾是否计入目标时长须在简报注明。

无录音时，可用普通中文对白约 3–4 字/秒作起算假设；按角色、表演、数字读法和专有词修正，不把这个范围当行业标准。标点不算发音字数，停顿单列。外语改用实际词速或朗读样本。

每句可记录：发音字数 ÷ 假设语速 + 停顿。两人轮流说话应累加，同一句对白与并行动作不重复加时。动作、情绪反应、可读文字要保留真实时间。

交付给出目标范围、估算区间、计时方法、是否实际朗读。超过目标先删冗余解释、调整动作和分场；不能只把语速调快。正式配音/动态分镜返回后校准，保留估算与实测差异。

## 四、适配 AI 制作

将“必须发生的故事信息”和“可以换实现方式的表现”分开：例如必须让观众知道有人入侵，未必一定拍一镜到底的百人追逐。

维护角色、服装版本、场景、关键道具的稳定 ID；脸、声音、惯用手等只在与叙事/资产一致性相关时定义。服饰、伤势、持物、天气、昼夜发生变化，要有场次依据。

对群演、大规模破坏、多角色接触、复杂连续运动、关键手部操作、跨镜头变形等标记制作风险，不一概判定不可做。记录风险缘由、当前制作方案、待验证事项和替代方案；模型能力应由当前实际测试验证。

资产预算由用户/制片指定，缺失时使用建议值并标为假设。预算维度至少区分常驻角色、一次性角色、地点、服装变体、关键道具与特殊场面。复用已有资产不能导致人物行为失真。

## 五、连续性

对每个相关集/场检查：

1. 时间顺序与路程是否成立？闪回/梦境是否可辨？
2. 角色知道什么、从哪一场知道？观众知道与角色知道分别记录。
3. 道具在谁手中、何时转移？证据是否有来源？
4. 伤势、服装、关系、承诺、资源和规则是否延续？
5. 伏笔何时投放、计划何时回收、实际如何回收？
6. 本集末状态是否支持下集开场？

## 六、问题分级与验收

| 等级 | 判断 | 处理 |
| --- | --- | --- |
| P0 阻断 | 核心因果矛盾、交接关键引用缺失、版本混用，导致无法可靠继续 | 修复后才能标为该范围审核通过 |
| P1 重大 | 动机/必要信息不足、超出项目硬性时长/资产预算、关键状态不连续 | 修复，或由指定负责人接受有依据的例外并记录影响 |
| P2 优化 | 不影响理解与交接的措辞、重复、节奏或表现优化 | 按本次目标修订；未处理可列后续建议 |

问题记录必须给出文件版本、集/场/对白 ID、证据、影响、建议、修复结果。不要用空泛的“节奏不够好”替代定位。

审核通过需要：本次范围内无未解决 P0；P1 已修复或有明确接受依据；必要交付项完整；估算、假设与未决项已标注。仅抽查时写“抽查范围内”，不可声称全季通过。未获得批准不能编造例外接受记录。

输出维度结论即可：叙事、人物、时长、连续性、可制作性、交接完整性分别为通过/需修订/未验证，并附证据。不以主观评分替代问题修复，不自动推断法律合规或发行审核结果。

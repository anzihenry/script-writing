## 冻结与隔离

公开输入为 `tests/fixtures/semantic-long-range/cases.json`，每例含六集正文和事实问题；答案只存于本目录 oracle.json。freeze.json 固定案例、oracle 及本次使用的两项技能和共享规则的 SHA-256。执行前先提交这些输入，评分阶段不得改动冻结内容。

六组错误/正常对照覆盖：知情来源、钥匙多次转移、闪回与当前状态、人物谎言与旁白确证、伏笔延期、相似台词下的错场引用。每组两例，六例预置 P1、六例正常对照；例子只覆盖所给六集，不推断未提供的后两集。

```bash
python3 scripts/prepare_semantic_round.py --round 1 --output /tmp/script-writing-round-1
python3 scripts/prepare_semantic_round.py --round 2 --output /tmp/script-writing-round-2
```

输出目录必须不存在。准备器核验冻结输入，只复制公开案例及必要准则，不复制 oracle、评分或另一轮结果；第一轮正序，第二轮反序。它不调用模型或启动代理。目录是评测材料隔离，不是操作系统访问沙箱；执行者还必须遵守只读指定目录的约束。

每轮使用独立的新上下文，只接收该目录的 request.md。保存原始 outputs.json 和执行者实际读取范围、环境、时间及限制，不用父执行者自审冒充隔离评测。执行者身份或具体模型不可取得时明确写未知，不猜测。

## 预先固定的评分规则

1. 预置问题：语义上指出 oracle 中的具体矛盾、等级 P0/P1 且给出足以支持的前后定位，记检出；泛泛说“连续性有问题”不计。severity 高于预置需说明理由。
2. 正常对照：每条 P0/P1 均需单独裁定；有据的额外发现不能自动算误报，无据的重大判断记误报。保留裁定原文。
3. 事实问题：逐例将 answer 与 required_facts 对照，记录完整/部分/错误/未答及原输出索引；不得把“未知”改写成肯定事实。
4. 证据：逐条检查 location 和逐字 quote 是否匹配对应小节，并人工复核是否支持结论。文本存在不等于语义支持。
5. 额外发现：单独列出、核对原文及规则，不加入预置问题分母，也不修改原答案抬高分数。争议保留为待裁定。
6. 最小修改：不能通过补造来源、默改正文或删除正常对照来消除问题；标明影响范围和未验证项。

每轮目标：6/6 预置重大问题检出，六例正常对照无无据重大误报，12/12 事实问题完整且有据，没有伪造引用或禁止推断。所有分子、分母按每轮分开报告。未达标如实保留输出和失败，不重复挑选最好一轮，不把有限样本外推为稳定准确率。

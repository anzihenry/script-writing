# 剧本生产交付模板

按任务复制所需部分，尖括号是待填写字段；不适用写“不适用 + 原因”，未知写“未定 + 影响”。最终交接稿不能残留未解释的空字段。

## 建议目录

```text
projects/<项目名>/
  brief.md
  bible.md
  outline.md
  continuity.md
  episodes/EP001-v1.0.md
  reviews/EP001-v1.0-review.md
  handoff/EP001-v1.0.md
  changes.md
```

小项目可合并文件；批量生产建议分开。JSON 仅在下游需要机器读取时增加，遵循交接协议，勿维护两个互相矛盾的正文。

## 1. 项目简报 brief.md

- 项目 ID / 名称 / 版本 / 状态：
- 模式：原创 / 改编 / 续写；来源与已提供的授权状态：
- 目标受众、题材、调性、语言与发行场景：
- 核心叙事承诺：观众持续观看希望得到什么？
- 一句话故事：
- 总集数 / 单集时长范围 / 片头片尾是否计入：
- 画面形态与画幅：真人质感 / 2D / 3D / 其他；未知则未定。
- 制作约束：常驻/临时角色数、地点数、服装变体、特殊场面、预算或可用资产。
- 用户指定不可改变的元素：
- 已确认事实 / 工作假设 / 未决项及影响：
- 本次交付范围 / 指定确认人（如有）：

## 7. 制作交接单

- 项目 / 集 / 剧本版本 / 状态 / 文件路径 / 设定与台账版本：

- 时长：目标、估算、朗读或配音实测情况。
- 场次清单、角色/场景/道具需求及已有资产引用：
- 对白表：逐句带 ID、角色、现场/画外等方式、文本、必要语气、所在场次；由正文提取，保留同一版本。
- 必须保留的动作、证据、揭示顺序及不能提前曝光的信息：
- 入场/出场状态与跨集连接：
- 屏幕文字、音效、环境声需求：
- 制作风险、可替代方案、需要样片验证的点：
- 未决项 / 负责人或负责视角 / 对下游影响：
- 接收方反馈：接收版本、问题定位、待返工项；未实际接收不得代填。

# AI 短剧剧本生产总入口

负责范围判断、阶段选择、依赖版本和交付衔接。实际执行由六个阶段入口组织三十个子技能；本入口不维护第二套写作步骤。

## 管线模式

批量生产、项目恢复或正式交接时，先读[生产管线](references/pipeline.md)和[操作手册](references/operations.md)。本目录的 `scripts/pipeline.py` 提供初始化、产物登记、依赖检查、关口检查和本地打包；只需 Python 标准库。工具不生成内容或自动批准。

- 新生产项目：在用户指定目录初始化；已有项目不可覆盖，先盘点并登记已有产物。
- 已有 project.json：先 check/status，读取过期和缺失项，再路由到最小阶段范围。
- 单项润色或咨询：仍可直接使用子技能，不强制初始化工作区。
- 阶段完成：更新问题与内容证据，登记当前产物，再运行对应 gate。结构就绪与内容审核结论分开报告。
- 请求交接包：执行 G5 后 bundle；未经用户请求不发送、发布或自行锁定。

## 阶段路由

先读[共同约定](references/common.md)，检查用户目标、已有材料和版本，再选择最小阶段集合。

| 阶段 | 何时使用 | 技能与交付 |
| --- | --- | --- |
| G0 立项 | 创意需要转成项目简报 | [ai-short-drama-brief](../ai-short-drama-brief/SKILL.md)：brief.md |
| G1 设定 | 需要总纲、结局、人物和世界规则 | [ai-short-drama-bible](../ai-short-drama-bible/SKILL.md)：bible.md |
| G2 拆集 | 需要连续的分集结构 | [ai-short-drama-outline](../ai-short-drama-outline/SKILL.md)：outline.md、伏笔计划 |
| G3 正文 | 需要某集或批次分场剧本 | [ai-short-drama-episode](../ai-short-drama-episode/SKILL.md)：剧本、连续性台账 |
| G4 审核 | 需要诊断、修订或复核已有稿 | [ai-short-drama-review](../ai-short-drama-review/SKILL.md)：报告、按请求修订的稿件 |
| G5 交接 | 需要分镜、美术、声音所用的剧本包 | [ai-short-drama-handoff](../ai-short-drama-handoff/SKILL.md)：交接单、台词表、资产需求 |

完整细项见[子技能目录](references/subskills.md)。明确要求伏笔、对白、估时等单一任务时直接读取对应子技能；无需先执行整个阶段。

## 协调步骤

1. 判定原创、改编、续写或修订，明确本次范围和终点。原文缺失不可声称完成忠实改编。
2. 从实际缺失的必要输入开始；已有材料直接复用。用户只要求试写时，补足最小暂定前提即可，不自动扩大为全季策划。
3. 只读取当前阶段入口、实际选中的子技能及其指定资料，通过文件执行，不要求新建聊天或启动子代理。
4. 多阶段任务按依赖继续，不在每个关口额外请求许可；单阶段任务到本阶段完成即止，说明下游输入而不自动执行下游。
5. 每阶段核对输入版本、产物、检查结果及未决项。上游变更后将依赖旧版的产物标为待复核，检查实际受影响部分。
6. 返工按问题归属：动机/规则回 G1，跨集结构回 G2，动作/对白回 G3，提取/引用回 G5。用户只要求诊断时交付报告，不改稿。

## 共享规范

[流程](references/workflow.md)定义检查点与版本；[标准](references/standards.md)定义写作和审核要求；[模板](assets/templates.md)供各阶段按需复制。示例、交接协议和资料来源仍在本目录维护。

阶段入口与子技能均可直接调用。整套包含 37 个相邻技能目录；分发阶段入口时须附带它引用的子技能和本目录共享资料。只有部分阶段的裁剪包不能承诺总入口的全流程能力。缺失依赖时说明具体文件，不假定已读。

完成时列出已完成阶段、文件及版本、未验证项和下一步输入。没有实际审稿或确认，不将产物标为 reviewed 或 locked。

# 示例：一分钟单集如何交接

这是用于演示规范的原创虚构微型故事，非用户项目，不代表已验证的成片。所有时间均为排演预算。

## 简报与设定摘录

项目 DEMO-RETURN《归还》；3 集微型悬疑；单集目标 55–65 秒，不含片头片尾。风格为克制的 2D 漫剧；成年受众。最多 2 个有台词角色、1 个常驻地点、2 个关键道具。这些是示例约束。

叙事承诺：一个声称来归还钥匙的人，为何不能看见值班室里的登记簿？

总纲：新任管理员林夏发现来访者持有从失窃登记簿上撕下的页角。她用错误的钥匙编号试探，对方纠正后暴露自己看过失窃页。最终她留下钥匙与纸片证据，并在门内致电管理处核对，来访者退去；身份留待管理处查验，但“此人是否只是拾获钥匙”的本段问题得到回答。

角色：CHAR001 林夏，谨慎但尚无经验的管理员，口吻短而具体；CHAR002 来访者，试图借归还钥匙取回失窃页的页角，先以礼貌掩饰焦急。林夏初始只知道登记簿缺页，来访者知道钥匙编号及缺页内容，双方不读心。

资产：LOC001 值班室（带不透明门及投递缝）；PROP001 铜钥匙；PROP002 登记簿（含可匹配撕口的页角状态）。CHAR001 固定灰色外套；CHAR002 本集仅画外声，不需要露出脸。

分集：EP001 发现撕口关联；EP002 用错误编号试探，来访者脱口纠正；EP003 门内保留物证并联系管理处，对方索要纸片暴露真实目的后离开。每集的变化推进调查，不新增超自然规则。

## EP001《页角》v1.0 / reviewed

依赖上述示例设定 v1.0。审核方式：作者自审。没有实际制作锁定依据，供预制作。

### EP001-SC001｜内｜LOC001 值班室｜夜

人物 CHAR001 在场，CHAR002 门外画外；道具 PROP001/PROP002。

入场：林夏在桌前，缺页登记簿摊开；钥匙和页角在门外来访者手中。林夏不知道来访者与缺页有关。

目标：在不开门的情况下核对归还物。阻力：来访者催促且说法含糊。场末变化：钥匙和包裹纸进入室内，纸片撕口与登记簿吻合，林夏决定试探。

| 块 ID（均前缀 EP001-SC001-） | 时间/预算 | 动作与对白 | 声音/文字 | 并行关系 |
| --- | --- | --- | --- | --- |
| B001 | 0–6 / 6秒 | 林夏翻到登记簿缺页处，手停在撕口；门外传来敲门声，她转头。 | 两声敲门 | 动作与敲门并行 |
| B002 | 6–14 / 8秒 | D001 CHAR001 现场：“谁？”；D002 CHAR002 画外：“捡到你们的钥匙，来还。” | 无屏幕文字 | 两句串行，留听答间隙 |
| B003 | 14–23 / 9秒 | 林夏站起，停在门侧。D003 CHAR001：“放门缝里就行。” D004 CHAR002：“你先开一下门。” | 门外衣料轻响 | 对白轮流，站起动作与 D003 并行 |
| B004 | 23–31 / 8秒 | 林夏不动。短暂停顿后，钥匙裹着纸片从投递缝落到接物托盘。 | 金属落盘声 | 停顿后动作；无需一镜连续拍完整过程 |
| B005 | 31–40 / 9秒 | 她取回物件，在桌面展开纸片。看向登记簿，又看纸片。 | 环境底噪 | 串行动作，无对白 |
| B006 | 40–50 / 10秒 | 她将纸片靠近缺页撕口，两者吻合。D005 CHAR002 画外：“纸也还我，别弄丢了。”她停止挪动纸片。 | 无需显示纸上可读文字 | 纸片对合与对白并行，留反应时间 |
| B007 | 50–60 / 10秒 | 林夏把纸片留在登记簿旁，拿起钥匙面向门。D006 CHAR001：“这钥匙，你在哪儿捡的？”门外没有回答。 | 结尾留约3秒无回应 | 台词、等待串行 |

对白完整 ID 为 EP001-D001 至 EP001-D006。时间块完整 ID 为 EP001-SC001-B001 至 B007。

出场：钥匙在林夏右手；登记簿与纸片在桌面。门未开。林夏知道纸片与缺页关联，但还不能断言来访者就是偷窃者；来访者不知道她已对合撕口。EP002 从门外迟疑后的答复接续，不重置持物。

导演约束：先让观众看到缺页，再展示纸片吻合；不能提前拍出来访者的真实目的。本集的回报是发现两件事有关，悬念是来访者为何要取回纸片。

制作方案：页角吻合可用两张静帧和剪辑表达，保留可比对的独特撕口图形；手部操作可拆成拾取/桌面/反应，不要求连续生成精确交接。若撕口不可读，应重新设计可辨识形状并更新资产，不用对白直接代替全部证据。

时长：6+8+9+8+9+10+10=60 秒；六句共 39 个中文发音字，3–4 字/秒约 10–13 秒，剩余为动作、停顿和等待。串行与并行按表核算。总表演暂估 55–65 秒，尚未实际朗读或制作动态分镜，不能称为实测 60 秒。

## 自审与交接结论

叙事、人物、文本连续性、交接信息：本示例范围通过；时长：预算通过、实测未验证；可制作性：已有替代方案、样片未验证。无制作锁定，也未有下游接收记录。

下游包包含上述资产、场次、完整对白和首尾状态；美术需准备撕口匹配的两种道具状态，声音需 2 个角色音色、敲门/金属落盘/衣料音及室内底噪。没有必须显示的屏幕文字。主要未决项为道具可辨识性和实际表演时长，应在分镜样片中验证。

## 局部修订示范

若反馈“林夏没有证据却说‘你就是偷登记簿的人’”，这是 P1 知情/推理跳跃。修订为追问钥匙来源，保留怀疑而不提前定罪；同步修订下集开场，把试探行动保留。不能只换这一句，却让下一集依然按‘已确认凶手’继续。上方正文已采用修订后的追问，这段是问题教学示范，不是实际外部审稿记录。

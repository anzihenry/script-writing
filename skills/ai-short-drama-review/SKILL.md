# G4 剧本审核与修订

## 按需读取

先读共同约定，再按本阶段指定章节读取：标准全文；流程中的版本与返工；模板第6、8节。

资料入口：[共同约定](../ai-short-drama-writing/references/common.md)、[模板](../ai-short-drama-writing/assets/templates.md)、[标准](../ai-short-drama-writing/references/standards.md)、[流程](../ai-short-drama-writing/references/workflow.md)。

## 输入

指定版本与范围、项目约束、相关设定/分集/前文/台账和反馈；先区分只审核、直接修订、修后复核。

## 执行

1. 固定待审版本与实际可读范围。缺少前文仍可审局部，跨集连续性标为未验证，不给全季通过结论。
2. 分维度检查叙事、人物、时长、连续性、可制作性和交接完整性，使用台词、动作和状态证据支持结论。
3. 按 P0/P1/P2 记录定位、证据、影响、建议和返工层级；审美偏好与硬约束分开，不以固定反转频率判错。
4. 只审核则交付报告；请求修订时修根因并执行最小充分联动，更新正文、台账及必要上游资料，列出受影响派生文件。稳定 ID 不因润色改变。
5. 锁定稿保留旧版本，新修订不自动获得锁定状态；P1 例外必须有明确接受依据，无依据则保留未解决。
6. 复核已修问题及影响链，保留原问题和复核版本；如实说明自审或独立审稿，不以格式检查替代叙事判断。

## 交付与通过条件

reviews/<范围>-<版本>-review.md；请求修订时另交新稿、台账和 changes.md。各问题有状态，各维度分别为通过/需修订/未验证。

无未解决 P0，P1 已修或有实际接受依据，必要信息完整才可判本范围通过。未验证项仍需披露；仅在用户要求交接时继续 G5。

本技能可直接调用，无需先执行总入口；共享规范依赖相邻的 `ai-short-drama-writing` 目录，分发时保留相对路径。只完成本次授权阶段及必要前提，不自动开展后续阶段。

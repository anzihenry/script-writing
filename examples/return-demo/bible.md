# DEMO-RETURN 设定 v1.0


项目 DEMO-RETURN《归还》；3 集微型悬疑；单集目标 55–65 秒，不含片头片尾。风格为克制的 2D 漫剧；成年受众。最多 2 个有台词角色、1 个常驻地点、2 个关键道具。这些是示例约束。

叙事承诺：一个声称来归还钥匙的人，为何不能看见值班室里的登记簿？

总纲：新任管理员林夏发现来访者持有从失窃登记簿上撕下的页角。她用错误的钥匙编号试探，对方纠正后暴露自己看过失窃页。最终她留下钥匙与纸片证据，并在门内致电管理处核对，来访者退去；身份留待管理处查验，但“此人是否只是拾获钥匙”的本段问题得到回答。

角色：CHAR001 林夏，谨慎但尚无经验的管理员，口吻短而具体；CHAR002 来访者，试图借归还钥匙取回失窃页的页角，先以礼貌掩饰焦急。林夏初始只知道登记簿缺页，来访者知道钥匙编号及缺页内容，双方不读心。

资产：LOC001 值班室（带不透明门及投递缝）；PROP001 铜钥匙；PROP002 登记簿（含可匹配撕口的页角状态）。CHAR001 固定灰色外套；CHAR002 本集仅画外声，不需要露出脸。

分集：EP001 发现撕口关联；EP002 用错误编号试探，来访者脱口纠正；EP003 门内保留物证并联系管理处，对方索要纸片暴露真实目的后离开。每集的变化推进调查，不新增超自然规则。



## 关系、规则与时间

CHAR001 起初只知道登记簿缺页，CHAR002 知道钥匙编号和页角来源；林夏不能在第 1 集直接证明对方就是偷窃者。
双方是陌生人。对方试图以礼貌换取开门，林夏选择保持门闭合。现实时间，连续一晚，无超自然机制、闪回或规则例外。

## 资产状态

LOC001 门不透明且有投递缝。PROP001 为铜钥匙；PROP002 包括缺页登记簿与关联页角，须有唯一可匹配撕口。CHAR001 灰色外套固定，本集 CHAR002 只需画外音。上述资产全部待制作。

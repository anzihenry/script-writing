# DEMO-RETURN 项目简报 v1.0

原创教学示例《归还》，无外部 IP 输入。成年受众，克制悬疑 2D 漫剧，中文，建议竖屏；这些均为示例设定，不是用户项目确认。

计划 3 集，各 55–65 秒，不计片头片尾；本次仅将 EP001 纳入生产登记。目标是展示剧本交接机制，不声称完成全季生产。

叙事承诺：归还钥匙的人为何执意拿走包裹钥匙的纸片？一句话故事：新管理员在不开门的条件下核实归还物，却发现包裹纸来自失窃登记簿，必须在暴露怀疑前确认对方来意。

示例硬预算：2 个说话角色、1 个常驻地点、2 个关键道具；不展示门外角色脸。保留纸片吻合这一可见证据。无实测模型能力、无生成素材、无商业授权或发行结论。

未决：实际朗读时长、纸片撕口可辨识性；不阻止文字开发，但进入样片验证后需要回填。
